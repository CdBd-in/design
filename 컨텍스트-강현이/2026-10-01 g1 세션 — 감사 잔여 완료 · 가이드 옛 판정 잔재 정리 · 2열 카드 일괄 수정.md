### 2. `~/.config/cdbd/cdbd.env` (헤드리스 로그인 · 6번 자동 재로그인에 필요)
그 기기의 `cdbd-templates/.env`에 같은 공용 계정 값이 있으면 두 줄만 옮긴다.
```bash
mkdir -p ~/.config/cdbd
grep -E '^CDBD_(EMAIL|PASSWORD)=' ~/Documents/GitHub/design/cdbd-templates/.env > ~/.config/cdbd/cdbd.env
chmod 600 ~/.config/cdbd/cdbd.env
sed 's/=.*/=…/' ~/.config/cdbd/cdbd.env     # 값은 가리고 키 이름만 확인
```
- g1에서는 `templates/.env`의 `CDBD_EMAIL`이 `credentials.json`의 계정과 **같다는 것만 비교로 확인**했다(값은 출력하지 않음). **g1 `cdbd.env`는 ⏳**(사용자에게 안내함).
- 🔴 `credentials.json`은 **복사하지 않는다**(refresh token이 쓸 때마다 바뀌어 복사본끼리 서로 무효화된다). 비밀번호는 다른 기기로 옮겨도 된다.

## 🔑 오늘 배운 것

1. 🔴 **인수인계 노트의 「결정」도 틀릴 수 있다** — 「버전 기록」을 고른 근거 「원격·허브 표기」는 사전을 `grep`해 보니 0건이었다. **명칭을 정할 때는 판정 원문과 사전으로 확인한다**(`fixedPosition`과 같은 교훈).
2. **근거 등급을 부풀리지 말 것** — 슬러그 규칙을 처음에 「📹」로 묶어 썼다가, 페이지 주소의 형식 에러는 촬영된 적이 없다는 걸 확인하고 ●로 낮췄다. **같은 규칙으로 보여도 화면마다 근거를 따로 단다.**
3. **멈춤 규칙이 낡은 상태 표시를 그대로 따른다** — SV 가이드는 「◐·○면 영상 대기라고 답하고 멈춘다」였다. 실측이 끝났는데 ◐ 표시가 남아 있으면 세션이 **답할 수 있는 질문까지 거절한다.** 상태 열을 고칠 때는 그 열을 읽는 규칙도 같이 본다.
4. **zsh의 `grep`(ugrep 별칭)은 git이 무시하는 하위 폴더를 건너뛸 수 있다** — 허브 루트에서 `grep -r .`을 하면 하위 볼트가 빠진다. **`/usr/bin/grep -r`에 볼트 경로를 직접 지정**한다.
5. **일괄 치환은 「뜻」으로 거른다** — 「2단」 576줄 중 카드를 뜻하는 건 235줄뿐이었다. 정정 문장(「「2단 카드」가 아니라…」) · 캡처 도구 기록 JSON · `[[링크]]` · 파일 이름은 따로 처리했다.
6. **Obsidian CLI가 꺼져 있으면 파일 이름을 바꾸지 않는다** — 링크가 깨지므로 셸 `mv`로 대신하지 않는다. 본문만 바꾸고 파일 이름은 보류했다.
