# 🔑 이번에 배운 「방법」 3가지 — 판정보다 이게 오래 간다

## ① 🚨 **「보이는 것」과 「넣는 것」은 다르다** (C단계에서 신설 · 가장 비쌌다)

**판정 82**(9/18)는 캔버스에 「`$$이름$$`」이 보이는 프레임을 근거로 *「데이터 태그 형식 = `$$열이름$$`」* 이라 결론냈다. **판정 105(9/20)에서 내가 「재확인」이라며 보강까지 했다.**

🔴 **둘 다 틀렸다.** `$$열이름$$`은 **Lexical `token` 노드가 렌더되는 표시 형태**다. 본문에 평문으로 치면 **발행 페이지에 글자 그대로 찍힌다.**

| | 에디터 화면 | 실제 발행 페이지 |
|---|---|---|
| 평문 `$$이름$$` | 「$$이름$$」 | 🔴 **글자 그대로** |
| 토큰 | 「$$이름$$」 | ✅ 「김재인」 |

> 🚨 **에디터에서 둘이 똑같이 보인다.** C단계에서 세션이 볼트대로 평문을 넣었고, **게시하고 개별 URL 5개까지 만든 뒤에야** 발각됐다.
>
> 🔑 **영상 판독은 「출력」만 본다. 「입력 형식」은 판독으로 확정할 수 없다.**
> · 판독으로 아는 것 — 무엇이 보이는가 · 문구 · 개수 · 순서
> · 판독으로 **못 아는** 것 — **어떻게 넣는가** · 평문인가 객체인가 · 커밋 조건
> 🎯 **그래서 C단계가 필요했다. B단계(문답)로는 절대 못 잡는다** — 세션이 볼트를 정확히 인용할수록 더 확실히 틀린다.
> 📌 **blur 커밋을 의심하라** — 여백 필드(A5)·열 이름(판정 134) 둘 다 **실타이핑 + 포커스 이동**이 있어야 커밋된다.

## ② 🚨 **정정을 「같은 칸」에 옛 서술과 함께 두면 안 된다** (감사에서 신설)

구간 10의 방법 ③(⏳와 단정이 **다른 파일**에 공존 금지)이 **더 작은 단위**에서 재발했다.

전수 감사에서 나온 최다 유형이 이것이다:
- L314 — 「✅ **반드시 「데이터」 버튼으로 삽입**」 **바로 옆에** 「⏳ 「데이터」 버튼 **위치 미확인**」
- L315 — 「✅✅ **모순 종결**」 **바로 옆에** 「⏳ **미확정**」
- L265 — 판정 109 반영 **바로 옆에** 「⏳ 전역인지 한정인지 미확정」

> 🔑 **세션은 한 칸 안에서 「실행 가능한 쪽」을 고른다.** "데이터 버튼을 써라 / 그런데 위치는 모른다" 를 같이 주면 **평문 타이핑으로 되돌아간다.**
> ✅ **규칙 — 판정을 반영할 때 그 셀 안의 옛 ⏳·단정을 반드시 함께 지운다.** 추가만 하는 것은 반영이 아니다.

## ④ 🚨 **빈 상태(0건)만 보고 「기능이 없다」고 하지 마라** (판정 135에서 신설)

**판정 123이 틀렸다.** *「권한 관리에 팀원 검색 기능 자체가 없다」*고 단정했는데, **팀원 0명 화면만** 본 결론이었다.
**팀원이 1명이라도 있으면 검색창이 나타난다** (`/permissions/6339` · placeholder 「이메일 계정을 검색하세요.」).

> 🔁 **등급 규칙(📹 > ●)이 뒤집힌 첫 사례다.** 소유자 확인(●)이 옳았고 **영상 판독(📹)이 틀렸다.**
> 🔑 **목록이 비면 검색·정렬·일괄 UI가 숨는 건 흔한 패턴이다.** 「**없다**」는 **가장 강한 주장**이니 **데이터가 있는 상태에서 다시 볼 것.**
> 🚨 **`cdbd-design-system/3-13. 권한 관리.md`를 「낡았다」고 고칠 뻔했다** — 그 문서가 옳았다.

## ③ 🚨 **판정을 쓸 때 그 주제로 `grep` 해서 옛 ⏳를 전수 확인한다**

9/20에 **「⏳를 해소한 판정이 나오면 그 ⏳를 적어둔 목록으로 되돌아간다」** 를 신설해놓고, **정작 판정 106을 쓸 때 A7 흔적 2곳을 안 지웠다.** B단계에서 세션이 *"아직 보충 목록 A7으로 남아 있습니다"* 라고 **스스로 모순된 답**을 냈다.

> 🔑 **규칙을 적는 것과 지키는 것은 다르다. 기억에 의존하지 말고 `grep` 하라.**

# 🔧 A단계 — 자동화 결함 5건, 전부 해결

> 📎 상세 = [[구간 1]] 「2026-09-21 자동화 결함 재검증」

## 🚨 결함보다 먼저 — **로그인부터 막혔다**

`~/.config/cdbd/credentials.json` 의 refresh token이 **16일째 만료**(`refresh_token_not_found`)돼 있었고 **아무도 몰랐다.** 볼트 서술도 틀려 있었다(「`$B state save cdbd` 쿠키 방식」 → 실제로 그 명령은 없고 **httpOnly 쿠키**, Chrome 프로필도 Default가 아니었다).

> ✅ **조치** — 토큰 재발급 + `[SV] _기능별 경로 가이드 §4-2「인증·세션」` 신설 + 사전 **§0-0-1** 신설
> 🚨 **「안다 ✅ / 할 수 있다 ❌」가, 결함 이전에 「로그인조차 안 된다」는 더 앞단에서 나타났다.**

| # | 결함 | 결과 |
|---|---|---|
| **A1** | 블록 필드명 틀림 | ✅ 실제는 **`disabled`·`active`** (`isShow`·`fixedPosition`은 **없는 이름**) |
| **A2** | `pinned` 항상 false | ✅ **핀은 블록에 저장되지 않는다** — 고정하면 **sortable 목록에서 빠진다**(6→5). 차집합으로 판별 → `pinnedIds()` |
| **A3** | 표시 토글 헬퍼 부재 | ✅ `setShown/isShown/toggleOf` 신설. 🔑 **표시 ON = `disabled:false`** (옛 `isShow`와 **의미 반대**) |
| **A4** | `dumpState()` 붕괴 | ✅ **`_sortableCtx`가 페이지 레일을 잡던 문제** — `4/0/4` → **`6/6/0`** |
| **A6** | `openImageUpload()` 실패 | ✅ **버그가 아니라 전제 문제** — 빈 이미지 카드에서는 정상. 이미지 **교체** 경로만 잔여 |
| ~~A7~~ | `blockOfRow` 전 행 null | 🔁 **철회 — 인덱스를 넣은 내 오용**(`blockOfRow(el)`은 엘리먼트 인자) |

> 🎯 **A4가 가장 컸다.** `dumpState()`는 검증 에이전트(V1~V5)·수정(F1)의 **입력 스냅샷**이다. 멀티페이지에서 통째로 깨져 있었으니 **멀티 문서 자동화는 전부 잘못된 입력 위에서 돌고 있었다.**
> 🔑 판별 단서 — **페이지 id는 nanoid**(`pPl1n-Q1nM…`) · **카드 id는 UUID**(`be3c1600-…`)

# 🎬 C단계 — 완주. 그리고 가장 값진 실패

**과제** 개인화 초청장 5명 · 브리프 → 게시 → 개별 URL 발급까지. **데이터에 함정 5개**를 심고 브리프엔 한 글자도 안 적었다.

| 항목 | 결과 |
|---|---|
| 💰 사전 고지 | ✅ **145C 정확** (게시 120C + 개별 URL 25C) |
| 🔴 빈 이름 행 | ✅ **예고까지** — "4행 고객은 빈칸을 봅니다" |
| 🔴 슬러그 | ✅ `slug_en` 사용 (한글·공백 불가 인지) |
| 대체어 | ✅ 기본 URL ↔ 개별 URL 구분 정확 |
| 직접 조작 | ✅ 게시·URL 발급·**5개 전부 열어 확인** |
| 변수 태그 | ◐ **틀렸는데 볼트 탓** → 판정 131 |

💰 **영수증** `520,650P → 520,505P` = **−145P**. 크레딧 0 그대로 → **판정 120 재확증**(차감은 잔액이 있는 쪽에서).

> ⚠️ **6-5(C/P 우선순위)는 여기서 못 풀었다** — 두 계정 모두 **한쪽이 0**이라 관측 불가. **500C 이상 충전 때만** 가능.
