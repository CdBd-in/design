## 이번 세션에 한 일

### 1. 구간 5 정본 반영 (판정 67~70)

`CdBd 기능 사전 (공통).md`

- **§4 전면 교체** — 행 5개 → 8개. 신설 = 「페이지 목록 패널」·「내보내기」·「에디터 헤더 — 게시 전/후」

- 상태 등급 **◐·● → 📹** 승격

**고친 오류 5건** (전부 실측과 반대로 적혀 있던 것)

| 옛 서술 | 실측 |

| [+ 페이지 추가] = **현재 다음에 삽입** | 🔴 **항상 맨 마지막** (복제만 원본 다음) |
| **호버** 복제·삭제 | 🔴 썸네일 **⋯ 메뉴 4항목** · 삭제는 **3장 이상일 때만** |

### 2. 🆕 하위 볼트 최초 동기화 — `cdbd-design-system`

> 🔴 **이 저장소는 독립 git이고 마지막 커밋이 2026-08-07.** 구간 1~5의 판정 70건이 **단 하나도 반영된 적이 없었다.**
> 지금까지의 관행 = 사전 충돌표에 「❌ `[DS] 4-1` 오류」라고 **기록만** 하고 DS 원문은 방치.

**방식** — 원문은 **지우지 않고** 🔴/📹 블록을 **병기**했다. 설계 의도 기록이 사라지면 "왜 이렇게 만들었나"를 못 찾기 때문.

| 파일 | 내용 |
|---|---|
| `3. 페이지 구조/3-2-5. 멀티페이지 에디터.md` | **불일치 8건** 병기 (아래) + 일치 4건 ✅ 표시 |
| `3. 페이지 구조/3-12. 뷰어.md` | 실측과 **일치** 확인 ✅ + 툴팁 원문·`page=N` URL·무한반복 연동 보강 |
| `cdbd-templates/.claude/agents/editor-s1-foundation.md` | 「멀티페이지 체크리스트」에 삽입 위치·삭제 조건·토스트 부재 보강 |

**`3-2-5` 불일치 8건**

1. 「새 페이지 만들기 모달」 — 🔴 **그 경로엔 모달이 없다** (에디터 내 [+ 페이지 추가] ↔ 목록의 [+ 새 페이지] **두 기능을 하나로 합쳐 서술**)
2. 사이즈 프리셋 **380×620** → 🔴 **380×580**
3. 「직접 입력 = 가로·세로」 → 🔴 **가로 380 고정 · 세로만**
4. 넘김 효과 **밀어내기/확대 1/확대 2** → 🔴 **밀어내기/덮기/종이책**
5. 페이지 설정 모달 = 2항목 → 🔴 **6항목** (무한 반복·자동 넘김·두 페이지씩·넘김 가이드 **누락**)
6. 「저장 없이 나가기」 모달 → 🔴 **존재하지 않는다**
7. 컨텍스트 메뉴 2항목 → 🔴 **4항목** (페이지 배경/정렬 설정 누락)
8. 페이지 이동 버튼 = 에디터 미리보기 좌우 40×40 · Disabled → 🔴 **에디터엔 없다(뷰어 전용)** · **Disabled가 아니라 미렌더링**

> ⚠️ 8번은 DS가 `≥1700px 전용`이라 단서를 달고 있는데 **촬영 시 뷰포트 폭이 기록되지 않아** 조건 충족 여부를 확증하지 못했다. **재확인 대상으로 남김** (4컬럼은 1401px부터 유지되므로 4컬럼 관측만으론 1700px를 증명 못 함).

✅ **DS가 맞았던 것** — 펼침 5열 그리드 · 새 페이지 = 목록 마지막 추가 · 복제 = 다음 순서 · **삭제는 3페이지 이상일 때만**.
✅ **자동화 레시피(`cdbd-preset-build-recipe.md`)의 「맨끝 append」도 이미 옳았다** — 사전만 틀려 있었다.

## 📌 이번 세션이 남긴 규칙

> 🔑 **「정본 반영」은 사전까지가 아니라 「그 기능이 사는 볼트」까지다.**
> 사전은 **요약 허브**고, 실제로 그 기능을 만들고 자동화하는 사람이 읽는 건 `cdbd-design-system`·`cdbd-templates`다.
> 사전만 고치면 **디자이너·자동화는 계속 틀린 스펙을 본다.** 구간 6부터는 반영 체크리스트에 **하위 볼트 칸을 포함**할 것.
>
> ⚠️ 하위 볼트는 **각자 독립 git**이다. 허브에서 커밋해도 하위는 안 올라간다 — **각 저장소에서 따로 커밋**해야 한다.
