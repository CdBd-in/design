# ✅ 미확인 재확인 작업 — 종료 (2026-10-05)

> **이 작업은 끝났다.** 다음 세션은 이 작업을 이어서 하지 않는다.
> 사전에 남은 ⏳ 표기는 **「모른다」는 표시로만 둔다** — 채우러 가지 않고, 추측으로 채우지도 않는다.

## 1. 무엇을 했나

| 단계 | 기간 | 판정 | 판정 원문 |
|---|---|---|---|
| 보충 2차 촬영·판독 (구간 11 · 13클립) | 10-04 | 139~151 | [[구간 11]] |
| 미확인 재확인 — 옛 클립 재판독 · 0.1~0.2초 정밀 재판독 · 브라우저 직접 확인 · 사용자 확인 | 10-04~05 | 152~176 | [[미확인 재확인 (2026-10-04~05)]] |

- 요청 원문(10-04): 「찍은 영상에서 못 본 것 다시 보고 · 영상 없이 확인 가능한 건 직접 확인해 기록 · **최후의 수단으로 영상이 필요한 것만** 알려줘」
- 마감 기준(10-05 사용자 결정): **「CdBd 에디터로 페이지를 만드는 데 필요한가」 + 「추측으로 만든 질문이 아닌가」** → 이 기준으로 걸러 **추가 촬영 없음**

## 2. 작업 방식에 영향을 주는 결론

| 결론 | 판정 | 실무 |
|---|---|---|
| 🔴 **페이지를 지우면 그 페이지로 걸린 링크는 눌러도 아무 일도 안 일어난다**(1페이지로 대체 이동도 없음) | 139 · 174 | 페이지 삭제 후 목차·메뉴 링크를 **반드시 다시 건다** · 링크 칸이 「1」로 보여도 데이터는 고쳐지지 않았다(173) |
| 🔴 삭제한 페이지도 **같은 세션이면 ← 실행 취소로 복원** · 새로고침하면 불가 | 140 | 실수로 지웠으면 새로고침 전에 ← |
| 링크 기본값은 멀티·원페이지·새 버튼 모두 **「URL 열기」** | 141 · 172 · 175 | 데이터엔 `linkButton`이 없다 = UI 기본값 |
| 스크롤 애니메이션은 **문서 전역**(`doc.theme.scrollAnimation` = `none`/`fade-up`/`zoom-in`) · **[저장하기]만 커밋** — [닫기]·✕는 버림, 바깥 클릭은 선택만 남고 저장 안 됨 | 143 · 162 · 168 | 반드시 [저장하기] |
| 페이지 배경 = 색상(Hex·RGBA) **또는** 이미지(원본/어둡게/밝게/흐리게) 택1 · 그 페이지에만 | 152 | — |
| 내보내기는 **항상 규격의 2배** · 배율 옵션 없음 · PDF는 `.pdf` 한 개 | 144 · 167 | — |
| 유튜브 **쇼츠는 임베드 안 됨**(「연결을 거부했습니다」) | 145 | 일반 `watch?v=` 주소 |
| 코드 카드 `<script>`는 **게시본에서도 실행 안 됨** · 영상 카드 많은 멀티는 방문자 화면에 iframe이 많이 뜬다 | 164 | 영상 로딩 보강은 CSS로만 · 페이지당 영상 수 줄이기 |
| 페이지 주소 규칙 = 3~30자 · 영문·숫자·`_`·`.` · 점으로 시작/끝 불가 · 하이픈 ❌ | 147 · 169 | — |
| 🔴 비밀번호 잠금 통과는 **24시간까지만** 유지(쿠키 고정 만료) | 170 | 고객 안내 = 「하루 동안 다시 묻지 않습니다」 |
| 데스크톱 뷰어는 **트랙패드·휠로 안 넘어간다** · 모바일 폭은 드래그로 넘어간다 | 146 · 153 · 176 | — |
| 멀티 페이지 수 **62장까지 추가 확인**(상한 미확인) · 💰 11장 이상은 자동화 게시 불가 | 165 | — |

## 3. 남겨 둔 것 — 지금 하지 않음

**프로젝트가 생기면 그때만 확인**
- 예약 카드 템플릿에서 「방문 체크가 언제부터 되냐」는 질문이 나오면 → 체크 가능 시간 산식(1건 관측 · 판정 87)
- 스마트스토어 상품 카드를 쓰는 프로젝트가 생기면 → 스토어 가격 변경을 카드가 따라가는지(판정 145 ⏳)

**제외(에디터 작업과 무관하거나 추측성 질문)** — 게시본 재확인 · 계정·결제 세부(내 주소 변경 · 복사본 공유 차감 · 권한 자리 세부 · C·P 순서 · 후불 · 계정 삭제 취소 · 구독 취소 화면) · 데이터 이미지 아이콘 클릭 · 예약 일괄 처리 · 방문자 QR 갱신 · 스캔 실패 화면 · 실기기 스와이프 · 비밀번호 재잠금 화면 · 스토어 최초 연동 동의 화면
