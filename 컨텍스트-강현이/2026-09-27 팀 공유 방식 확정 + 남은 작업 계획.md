| | **A. 플러그인** (마켓플레이스) | **B. 허브 `CLAUDE.md`만** (9/22 안) | **C. 설치 스크립트 + 전역 연결** ✅ 추천 |
|---|---|---|---|
| 어느 폴더에서 켜도 지식 로드 | ✅ | ❌ `design/` 안에서만 | ✅ `~/.claude/CLAUDE.md`에 `@import` |
| 어느 폴더에서 켜도 스킬 로드 | ✅ | ❌ `cdbd-templates`에서만 | ✅ `~/.claude/skills/`에 **심볼릭 링크** |
| 정본이 한 벌인가 | ❌ 플러그인은 **캐시로 복사**됨 → 스킬 2벌(= 지금 1번 문제의 재발) · 사전 539줄은 결국 clone 필요 | ✅ | ✅ 링크가 저장소 파일을 직접 가리킴 |
| 최신화 | 마켓플레이스 update **따로** + git pull | git pull | **git pull 하나** (링크라 즉시 반영) |
| 인증·브라우저(층 3·4) | ❌ 별도 해결 필요 | ❌ | ✅ 스크립트가 설치·점검 |
| Claudian에서 동작 | ⚠️ 미확인 | ✅ | ✅ 단, Claudian 「사용자 설정 불러오기」 ON 필요 |
| 만드는 비용 | 3~4시간 + 층 3·4 별도 | 15분 (하지만 목표 미달) | 4~5시간 |

**결정: C.** 두 팀원 모두 어차피 저장소를 clone해야 한다(스킬·사전이 저장소에 있음). 그렇다면 플러그인은 「복사본 한 벌 더」일 뿐이고, 진짜 빈 곳(층 3·4·6)은 플러그인이 해결하지 않는다.
→ **나중에 clone하지 않는 사람이 3~4명 이상**이 되면, C의 전역 연결 부분(C1·C3·C9)만 플러그인으로 포장한다. 지식은 여전히 clone.

```

├─ CLAUDE.md                     ← C1 허브 라우터 (≤80줄)

├─ ONBOARDING.md                 ← C8 「Claude 셋업」 챕터

└─ 검증/팀원 수용 테스트.md        ← C7
```
