| | 문제 | 대응 |
|---|---|---|
| ① | **토큰 충돌** — refresh token이 **쓸 때마다 바뀌는 회전형**이라, `credentials.json`을 복사해 주면 한 기기가 갱신하는 순간 다른 기기 토큰이 죽는다 | **기기마다 각자 로그인해 자기 세션을 갖는다**(같은 계정이어도 세션은 기기별로 독립). `credentials.json` 복사 금지 · 만료·무효 시 `cdbd.env`로 **자동 재로그인**(7-A) |
| ② | **같은 페이지 동시 편집** — 두 Claude가 같은 에디터를 동시에 조작하면 서로 덮어씀 | 사람마다 **전용 테스트 페이지 id** · 허브 `CLAUDE.md`에 「남의 작업 페이지 조작 전 확인」 1줄 |

| + | 비밀번호를 바꾸면 **모든 기기가 동시에** 재로그인 실패 | `cdbd-doctor.sh`가 「cdbd.env 비밀번호 갱신 필요」로 원인을 바로 표시 |

### Claudian이라서 생기는 것

- Claude의 작업 폴더 = **Obsidian에서 연 볼트**. 어느 볼트를 열든 동작해야 한다 → 허브 `CLAUDE.md`(상위 폴더 자동 로드) + 사용자 폴더 전역 연결 둘 다 필요.
- 전역 연결(`~/.claude/CLAUDE.md`·`~/.claude/skills/`)은 Claudian **「사용자 설정 불러오기」(`loadUserSettings`)가 켜져 있어야** 읽힌다. **기본값 ON**(이 맥 확인) · 볼트별 `.claudian/claudian-settings.json`에 저장 → doctor가 점검.
