## 4. 최종안 구조 (위→아래)
1. **히어로**(검정 점무늬) — 「기업용 모바일 페이지 빌더」 배지 · 「필요할 때 바로, / 모바일 페이지 / 제작은 **CdBd**(그린 스티커)」 · 보라 「무료로 시작하기」 + 흰 「고객 사례 보기」 · 목업 6대(한국게임 이노베이션 허브 · 샤넬 · 티파니 · 티쏘 · 삼성 에스원 · 랄프스 커피) 부채꼴 → 스크롤하면 한 줄, 멀티페이지는 3초마다 페이지 넘김
2. **왜 CdBd인가?**(흰 점무늬) — 「간단한 모바일 페이지 / 하나에도 **고민이 많아집니다.**」 · 카드 3장(보라·진보라·검정)이 스크롤하면 겹쳐 쌓임 · 항목이 밝아질 때 사진의 해당 부분 확대 · 「그래서, **CdBd.**」 + 보라 시작 버튼
3. 고객사 로고 → 4. **비즈니스별 활용 사례**(검정 · 카드 6장 · 대표 사례 목업) → 5. **고객 사례**(5유형 × 2건) → 6. **핵심 강점**(보라 · 카드 4장 · 실제 화면 움직임) → 7. **첫 URL 평생 무료**(그린) → 8. **요금 안내**(원페이지 120크레딧(C)~ · 멀티페이지 100크레딧(C)~ · 모든 요금 보기) → 9. 블로그 → 10. 가이드센터(그린) → 11. 자주 묻는 질문 → 12. 푸터
- 섹션 경계 = 다음 섹션의 둥근 위 모서리가 겹치는 방식(물결 아님)
- 오른쪽 아래 고정 버튼: 「상담 신청하기」(메뉴 알약 색) + 「가입 없이 무료로 시작하기」(그린) · 받침 없음

## 5. 디자인 규칙 (최종 · 시안 CSS 끝부분에 주석으로 있음)
- **글자**: Pretendard만 · 굵기 ≤700 · 최소 16px · 크기 9단계(`--fs-d … --fs-n`) · 자간 최대 -3.5%
- **버튼**: 모양 하나(알약 · 외곽선 없음 · 그림자 없음) · 색으로만 구분
  - 주(시작하기) = 히어로·그래서 CdBd **보라** / 고정 버튼 그린 / 그린 섹션 안 = 검정
  - 보조(보기·신청·받기) = 밝은 바탕 검정+흰 / 어두운 바탕 흰+검정 · 사례 카드 「시작하기」 검정
- **강점 핵심어 스티커**(제목마다 한 곳 · -2.5° · 그림자 없음): 밝은 바탕 = 검정 상자+그린 글자 / 어두운 바탕 = 그린 상자+검정 글자
- **라벨 알약**(-2° · 그림자 없음): 흰·연보라 바탕 = 보라 / 비즈니스별 활용 사례(검정) = 보라 / 핵심 강점(보라) = 검정 / 그린 바탕 = 검정
- **카드**: 테두리·그림자 효과 없음으로 통일
- **목업**: 원페이지 = 실제 페이지 길이만큼 천천히 스크롤 / 멀티페이지 = 1~3쪽 3초마다 넘김 · 원래 목업 프레임 사용
- **가변 데이터 사례**: 빈 칸에 예시 「김하나」를 채워 보여 준다(에스원 과장|보안사업팀 · 샤넬 김하나 팀장님 · 경기도 15기 CdBd 디자이너)
