## 1. 확정한 규칙 (요약 — 상세는 정본)

| 항목 | 규칙 |
|---|---|
| 찾기 | Claude는 피그마 안에서 **검색을 못 한다** → 볼트 **주소록**(브랜드 → 파일 링크)이 입구. 토큰(PAT)은 90일 만료라 상시 운영에 쓰지 않는다 |
| 파일 | **브랜드당 1개** · 이름 = 브랜드명 한글(`마이클코어스`) · CdBd와 메이크뷰를 한 파일에 · 브랜드 = **로고가 찍히는 브랜드**(한섬 같은 고객사는 브랜드별로 나눔) |
| 페이지 | 작업 1건 = 페이지 1개 · 이름 **`YYMM 주제`**(부르기 쉬운 한글) · 순서 `Cover` → `----- CdBd -----` → CdBd 작업들 → `----- 메이크뷰 -----` → 메이크뷰 작업들 · 묶음 안에서 최신이 위 |
| 섹션 | **`✅ 최종 (초안)`**(마지막 초안 · 게시 여부 무관 · 한 벌만) / `시안`(고른 안에 ✅) / `작업대` |
| 에디터 번호 | CdBd 작업은 최종 섹션 이름 끝에 `· 에디터 ○○○○` |
| 다음 작업 | **이전 작업 에디터를 「복제하기」해서 복사본에서** 작업 · 원본은 건드리지 않음(게시 중 · 자동저장) |
| Cover | 1920×1080 · 검은 배경 · 브랜드 로고 가운데 · 썸네일 지정은 사람이 |
| 원래 파일 | 합치고 남은 월별 파일은 **일단 보관**(`_보관` 폴더 · 지우지 않음) |
| 드라이브 저장 | **피그마 작업 완료 + 에디터에 이미지 반영 직후** ① 에디터에 들어간 이미지 2배 → `0.CdBd 커스텀 템플릿 서비스/{브랜드}/{YYMM}_{브랜드}_{담당}/작업파일/{시안\|초안}/` ② 브랜드 `.fig` 원본(Claude가 **File → Save Local Copy** 직접 클릭) → **브랜드 폴더 바로 아래** · `{브랜드}_{YYMMDD}.fig` · **최신 1개만** |

## 3. 실측으로 알게 된 것 (함정)

| 무엇 | 실측 |
|---|---|
| `get_metadata`(nodeId 없이) | **열린 페이지만** 보여 준다 — 2608 파일 페이지 3개가 1개로 보였다 → 페이지 목록은 `use_figma`의 `figma.root.children` |
| 2배 이미지 | `get_screenshot`은 1배까지 · `exportAsync` 반환은 20KB 제한 → **`use_figma`에서 `frame.screenshot({ scale: 2 })`** → 로컬 저장 파일을 복사 · 한 호출 5장까지 |
| Save Local Copy | 저장 창에서 ⌘⇧G 안 열림 → 기본 위치(다운로드)에 저장 후 `mv` · 파일명은 텍스트 필드 `value` 직접 설정 |
| 파일 간 옮기기 | API 불가 → 데스크톱 앱: `open -a Figma URL` → `screencapture`로 탭 확인 → **메뉴 클릭** Edit → Select All / Copy / Paste(키 입력·캔버스 클릭은 안 먹음 · `AXRaise` 먼저) → `clipboard info`에 `«class HTML»` → 붙인 뒤 `use_figma`로 요소 수 대조 |
| 🔴 탭 전환 사고 | 붙여넣기 순간 탭이 **큐알스탬프**(`VS96FiThWiv0HSOUcg3Py4`)로 바뀌어 거기 7개가 붙음 → `use_figma`로 **붙은 7개만 삭제**(리서치 프레임 `3:2`는 보존). 다른 세션이 같은 피그마 앱을 쓰는 중이었던 것으로 보임 → 붙여넣기 후 대조 필수 |
| 파일 주소 찾기 | 피그마 데스크톱 `~/Library/Application Support/Figma/settings.json`에 열린 탭 목록(`path` · `title`) |
| 파일 브라우저 화면 | 사이드바 클릭이 먹지 않음(osascript `click at` · CGEvent 둘 다) → 폴더 목록은 화면 조작으로 못 읽음 |
| 권한 (이 기기 설정 완료) | 시스템 설정 → **손쉬운 사용 · 화면 및 시스템 오디오 녹음 → Obsidian** — 기기마다 1회 · 이선호 님 기기도 필요 |
