## 1부 — 가이드 설계에서 배운 것 (확산 시 그대로 적용)

1. **구조 = 「기능 사전 → 라우팅」 2단.** 라우팅만 있으면 팀원이 다르게 말할 때 매칭 실패. 앞에 한 줄 정의 사전을 세워 *기능 특정 → 파일 라우팅* 순서로.
2. **행동 게이트는 파일 맨 위 + 명령문.** §5 하단에 표로 넣었다가 **2번 연속 실패**. 맨 위로 올리고 *"첫 응답은 질문 한 줄이어야 한다. 분석·조회·파일 열기 전부 금지"*로 바꾼 뒤 통과.
3. **관찰된 실패를 그대로 금지 조항으로** — *"분석을 다 해놓고 맨 끝에 되묻는 것 = 위반"*
4. **`@import` 파일의 지시는 `CLAUDE.md` 본문보다 약하다** → 중요한 게이트는 CLAUDE.md에도 압축본 1줄(이중 안전장치).
5. **범위 = CdBd 제품 기능만.** Figma 제작·팔레트·폰트는 CLAUDE.md 파일 맵이 이미 담당 → 넣으면 매 세션 이중 로드. (📌 **나중에 넓히기로 함**)
6. **볼트 간 링크는 작동 ❌** → 허브 사전을 가리키지 말고 **내용을 복사**해 self-contained로.

### 검증 방법 (재사용)
- 대화 기록에서 실제 연 파일 추출 → `python3 "_경로가이드-검증.py" [저장소명]`
- **@import 로드 확인 카나리아** — `"카드의 세로 스택"이 무슨 뜻이야?` (그 문구는 [T] 가이드에만 존재). 검색 없이 답하면 로드된 것.
- **가짜 통과 차단** — `1-7`에만 있고 CLAUDE.md엔 0건인 값을 물을 것: 썸네일 배경색 `S 15~30% · L 78~88%`
