# 팀원 수용 테스트

> **목표 판정** — 팀원 기기의 Claude가 **어느 볼트에서 켜도** 아래 문항을 전부 통과하면, 실행 계획서의 목표(「어느 팀원이 Claude에게 CdBd 기능을 시켜도 다 알고 제대로 동작한다」)에 도달한 것으로 본다.
> 🔒 **이 문서에는 문항만 있다. 기대 답(채점 기준)은 볼트 밖에 둔다** — 세션이 정답지를 읽고 답하면 정본을 읽었는지 구분할 수 없다(2026-09-16 구간 4 게이트 사고). 채점 기준 = 볼트 밖 `구간별 테스트 채점표.md` 「수용 테스트」 절.

## 실행

```bash
bash "검증/수용테스트.sh"                          # design/ 에서 실행 · 결과는 볼트 밖에 저장
bash "검증/수용테스트.sh" --key "<채점표 경로>"     # 채점까지 자동
bash "검증/수용테스트.sh" --only Q07,Q08            # 일부 문항만
```

- 새 `claude -p` 세션을 **문항마다 따로** 켠다(이전 대화 영향 없음). 도구는 **Read·Grep·Glob만** 허용 — 파일 수정 · 에디터 조작 · 💰 과금이 일어날 수 없다.
- 결과 = `~/Desktop/cdbd-수용테스트-결과/<시각>/` (문항별 답 · 도구 사용 횟수 · 채점). **볼트 안에 저장하지 않는다.**
- 「첫 응답은 질문 한 줄」 문항은 **도구 사용 0회**여야 통과다.
