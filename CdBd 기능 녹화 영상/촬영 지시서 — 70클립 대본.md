# 구간 1 — 에디터 공통 (8클립 · 촬영 100분)

> **여기가 모든 작업의 기반입니다.** 1구간만 먼저 찍어 보내주시면 촬영 페이스와 제 판독 정확도를 실측해 나머지 견적을 정확히 맞출 수 있습니다.

## 1-1. 에디터 3보드 + 상단 헤더 (2분)

1. 원페이지 테스트 페이지를 에디터로 엽니다
2. ⏸ **3보드 전체가 보이게** 정지 — 좌 미리보기 / 중 카드보드 / 우 디자인보드
3. **상단 헤더를 왼쪽부터 오른쪽까지** 천천히 마우스로 훑기 (← → · 페이지 이름 · 💡 · 🎨 · 👁 · URL 버튼)
4. ⏸ **URL 버튼 라벨 정지** — `URL 생성하기`인지 `게시하기`인지 (게시 여부에 따라 다름)
5. 좌상단 **로고에 마우스 올리기** → ⏸ **드롭다운 전체 정지** (홈·내 페이지·내 계정·도움말·로그아웃)

> 🔴 **확인 사항** — 「내 계정」이 정말 이 로고 메뉴 안에 있는지. 문서마다 진입 경로가 다릅니다.

## 1-2. 카드 보드 — 추가·순서·토글 (4분)

1. **[+ 카드 추가하기]** 클릭 → ⏸ **카드 선택 목록 전체 정지** (15종이 다 보이게, 필요하면 스크롤)
2. 텍스트 카드 추가 → 추가 직후 화면이 어떻게 되는지 (자동 선택되는지)
3. 카드를 **드래그해서 순서 변경** → 드래그 중 화면 · 놓은 뒤 화면
4. 카드 **ON/OFF 토글 끄기** → ⏸ **카드보드에서 어떻게 보이는지 정지**
5. 그 상태에서 **드래그를 시도** → 되는지 안 되는지
6. **카드명 편집**을 시도 → 되는지
7. 토글 다시 켜기 → 선택 상태가 어떻게 바뀌는지
8. 👁 미리보기에서 **OFF 카드가 안 나오는지** 확인

> 🔴 **확인 사항** — OFF 상태에서 ① 드래그 ② 고정 ③ 케밥 ④ 카드명 편집 중 **무엇이 되고 무엇이 안 되는지.** 문서엔 표가 있지만 실제와 같은지 미확인입니다.

## 1-3. 카드 보드 — 핀(고정) 전체 (3분)

1. 카드 하나의 **핀 아이콘** 클릭
2. ⏸ **드롭다운 정지** — 상단/하단 선택지가 뜨는지
3. **상단** 선택 → 카드보드·미리보기에서 무엇이 달라지는지
4. 고정된 카드를 **드래그 시도** → 되는지
5. **다른 카드를 또 상단에 고정** 시도 → ⏸ **교체 모달 전문 정지** (문구가 읽히게)
6. [교체하기] 선택 → 기존 카드가 어떻게 되는지
7. 핀 **해제** 클릭 → ⏸ **확인 모달 정지** → [해제하기]

> 🔴 **확인 사항** — 상단·하단 각 1개까지만 고정되는지, 3개째는 어떻게 되는지.

## 1-4. 카드 보드 — 케밥 더보기 메뉴 (2분)

1. 카드 우측 **케밥(⋮) 클릭** → ⏸ **메뉴 항목 전체 정지**
2. **[내 카드로 저장]** → 어디에 저장되는지, 어떻게 다시 쓰는지까지
3. **[복제]** → 복제된 카드가 어디에 생기는지
4. **[삭제]** → 확인 모달이 있는지, 바로 지워지는지
5. ← 되돌리기로 복구되는지

## 1-5. ⭐⭐ 디자인 보드 — 카드 디자인 (5분 · 전체 최우선)

> **가장 중요한 클립입니다.** 우리 시안·프리셋 규칙 전체가 여기 걸려 있습니다.

1. 카드 하나 선택 → 우측 디자인 보드에서 **[카드 디자인]** 아코디언 펼치기
2. ⏸ **항목 이름이 전부 읽히게 위에서 아래로 천천히 스크롤** (배경·테두리·모서리·내부여백·외부여백…)
3. **배경** — 기본 색상 팔레트 전체 ⏸ → 색상 직접 입력 (Hex/RGB/RGBA 탭이 각각 있는지 ⏸)
4. **배경 이미지** 추가 → **밝기 옵션 전체** ⏸ → 하나씩 적용
5. **테두리** — 두께 0 → 4까지 천천히 · 색상 변경
6. **모서리** — ⏸ **선택지가 몇 개인지 정지** → 하나씩
7. **내부여백** — 기본 상태에서 0 → 40까지 천천히
   - ⏸ **슬라이더 숫자가 읽히게 정지** — 1씩 움직이는지 2씩 움직이는지
   - **확장(▾) 아이콘 클릭** → ⏸ **나오는 슬라이더가 몇 개인지 정지**
8. 🔴🔴 **외부여백 — 이번 촬영에서 가장 중요한 장면**
   - 기본 상태 조절
   - **확장(▾) 아이콘 클릭**
   - ⏸⏸ **나오는 항목이 「위·아래」 2개인지, 「상·하·좌·우」 4개인지 반드시 화면에 담아주세요**
   - 4개라면 **좌 슬라이더를 20까지 올려** 미리보기가 실제로 좁아지는지
9. 여백 최댓값이 정말 40인지 (더 올라가는지)

> 🔴🔴 **판정 대상 2건**
> ① **외부여백에 좌우가 있는가** — 우리 문서는 "있다"(2026-06-19 사용자 검증), 제품 문서는 "상하만"
> ② **슬라이더 단위** — 우리 문서는 "1 = 1px", 디자인시스템은 "0~40, 2단위 21단계". 숫자가 1씩 가는지 2씩 가는지

## 1-6. 페이지 테마 (4분)

1. 상단 **🎨 팔레트** 클릭 → 디자인 보드가 페이지 테마로 바뀌는지 · 카드 선택이 해제되는지 ⏸
2. **색상** — 배경 / 텍스트 / 버튼 각각 변경 → 미리보기 전체가 바뀌는지
3. **배경 종류** — ⏸ **선택지 전체 정지** (단색·그라데이션·이미지·동적 배경이 다 있는지) → 하나씩
4. **버튼 모양** 일괄 변경
5. **서체** — ⏸ **목록 전체가 보이게 스크롤** (한글·영문 몇 개인지 셀 수 있게 천천히)
6. **[테마 저장]** / **[내 테마]** → 저장한 테마를 다시 불러오는 것까지

## 1-7. 미리보기 + QR (2분)

1. 👁 **미리보기** 클릭 → 새 창이 뜨는지
2. 미리보기 화면 전체 스크롤
3. 에디터에서 카드를 하나 수정 → 미리보기 창으로 돌아가 **F5 없이 반영되는지** → F5 후
4. 미리보기 화면의 **QR 다운로드** → ⏸ **PNG/SVG 선택지 정지** → 둘 다 받아보기

## 1-8. ⭐ URL 생성 / 게시 모달 (5분)

1. 상단 **[URL 생성하기]** 클릭 → ⏸ **모달 전체 정지**
2. **슬러그 입력** — 하이픈(`-`)을 넣어보기 → ⏸ **에러 문구 정지** · 그다음 언더바(`_`)로 바꿔보기
3. **이미 쓰는 주소** 입력 → ⏸ **중복 에러 문구 정지**
4. **OG 썸네일** 업로드 → 미리보기가 어떻게 보이는지 · 권장 규격 안내 문구 ⏸
5. **제목·설명** 입력
6. 🔒 **비밀번호 보호** — ⏸ **어디에 있고 어떻게 켜는지** · 켠 뒤 입력란
7. 🗂️ **페이지 상단 메뉴** 토글 → ⏸ **기본값이 켜짐인지 꺼짐인지 정지**
8. 🖥️ **사이드바** 토글 → ⏸ **기본값 정지**
9. **이용 기간** 선택 → ⏸ **차감 크레딧 표시가 보이게 정지** (1개월/2개월/12개월 각각)
10. **CdBd 배너 유지** 체크 → ⏸ **할인 적용된 금액 정지**
11. **[게시하기]** → 완료 화면 → 생성된 URL이 보이게 ⏸

> 🔴 **확인 사항** — 상단 메뉴·사이드바의 **기본값**. 문서마다 "기본 켜짐"과 "기본 OFF"로 엇갈립니다.

## ✅ 구간 1 완료 게이트 — 편집 반영 테스트 (30분)

> 대상 판정 = 1~13 (카드 14+2열 6종 · OG 800×400 · 외부여백 좌우 · 이미지 탭 이름 · refresh 파라미터 · 핀 교체 모달 · OFF 제한)

| # | 새 세션에 **그대로 붙여넣을** 지시 | ✅ 합격 | ❌ 불합격 (= 판독 전 오답) |
|---|---|---|---|
| 1 | 「Figma 시안대로 이 텍스트 카드 여백 맞춰줘. **좌우 각 40px 안쪽, 위아래 0, 안쪽 패딩 24**.」 | 외부여백을 **확장(∧)** 한 뒤 **상0 하0 좌40 우40** · 내부여백 24×4 | *"외부여백은 상하만, **좌우 불가**"* · *"최대 **40**이라 불가"* · **시안 수정 요구** |
| 2 | 「미리보기에 수정이 반영이 안 돼.」 | 👁를 **다시 열어** `viewer?refresh={timestamp}`로 갱신 | **F5 / 새로고침** 안내 |
| 3 | 「이 카드에 무료 이미지 하나 넣어줘.」 | 이미지 추가 모달의 **「이미지 검색」·「GIF 검색」** 탭 | **「Pexels」·「Giphy」** 탭 (제품 UI에 없는 이름 → 팀원이 못 찾음) |
| 4 | 「이 페이지 카톡 공유용 썸네일 규격 알려줘.」 | **800×400** | **1200×630** |

# 구간 2 — 카드 (15클립 · 촬영 180분)
> ⚠️ **「15종」이 아니다.** 제품 카드 = **기본 14종 + 2열 6종**(영상 1-2 실측). 15는 **클립 수**.

> **공통 방식** — ① [+ 카드 추가하기]로 추가 → ② 우측 패널 옵션을 **위에서 아래로 하나씩** 조작 → ③ 좌측 미리보기 변화를 확인.
> **각 카드 시작 시** ⏸ **우측 패널 전체를 천천히 스크롤**해 **항목 이름이 다 읽히게** 해주세요. 이게 있으면 옵션 누락을 제가 잡아낼 수 있습니다.

## 2-1. 텍스트 (2분)
1. 텍스트 입력
2. 🎚 **크기** — 슬라이더를 **왼쪽 끝까지** → 더 끌어보기 ⏸ → **오른쪽 끝까지** → 더 끌어보기 ⏸ → 숫자 입력란에 **0**과 **999** 넣어보기 ⏸
3. 🎚 **줄간격** — 같은 방식(양 끝 + 범위 밖 값) ⏸
4. **드래그로 일부만 선택** → 부분 스타일 적용
5. 정렬 · 색상 · 굵기(B) · 밑줄(U)
6. 서체 [+ 서체 더하기] → ⏸ **한국어 탭 전체** → ⏸ **ENG 탭 전체**

> ✅✅ **2-1 완전 종결** (본편 + 보충 + **재촬영 2026-09-15**). 서체 44종·이탤릭 없음·부분 스타일 확인.
> ✅ **슬라이더 실범위 확정** — 크기 **12~60**(선형) · 줄간격 **1.2~2.0 step 0.2** · 여백 **0~40 step 2**.
> 🔁 이 재촬영으로 **9/4 판정 3건(14·15·5b)이 철회**됐다 — 전부 팀 문서가 옳았고, 입력란 값을 슬라이더 범위로 오인한 것.

## 2-2. 🔴 이미지 (3분)
1. 이미지 추가 → ⏸ **3경로 정지** (내 이미지 / Pexels / Giphy) → 각각 열어보기
2. 🔴 **모양 옵션** — ⏸⏸ **선택지가 몇 개인지 정지** (라벨이 읽히게) → 하나씩 적용
3. **비율** — ⏸ 선택지 전체 → 하나씩
4. **레이어 추가** → 무엇이 얹히는지
5. 링크 연결 → ⏸ **종류 목록 전체 정지**

> 🔴 **판정** — 모양이 **3종**(각진·둥근·원형)인가 **8종**(+아치·구름·꽃·반짝이·마름모)인가. 우리 문서는 8종, 제품 문서는 3종.

## 2-3. 🔴 갤러리 (4분) — ✅✅ **완전 종결** (본편 + 보충 2026-09-15)

> ✅ 유형 3종(**나열하기/넘겨보기/그리드**) · 넘겨보기 토글 4종+초 · **확대 보기 허용/허용안함** 🆕
> ✅ **그리드 단수 슬라이더 2·3·4단 + 간격 슬라이더** · 🎯 **2단 이상에서도 비율 1:1 강제 안 됨**
> ✅ **비율이 유형마다 다름** — 그리드 `원본/1:1/가로/세로` · 넘겨보기 `직접입력/1:1/3:2/2:3`
> ✅ **16장째 경고 = 「15장까지만 추가할 수 있습니다.」**
> ✅ **링크 연결 8종 + 하위 필드 전부** — 이미지 카드 7종 + **「페이지 이동하기」** · 갤러리는 **이미지별 개별**

# 전달 방법

- 파일 그대로 주시면 됩니다. **제가 프레임으로 뽑아 읽습니다**(ffmpeg). 편집·자막 불필요
- 여러 클립을 한 영상에 몰아 찍으셔도 되지만 **클립 사이 3초 정지** — 구간을 나눌 수 있습니다
- **구간 단위로 보내주세요.** 한 구간이 끝나면 제가 판독→기록→충돌 판정→**정본 반영**까지 마치고, 다음 구간 전에 **놓친 화면이 있으면 그때 알려드립니다** (몰아서 찍고 나중에 재촬영하는 것보다 훨씬 쌉니다)
- **그다음 「완료 게이트」를 같이 돌립니다.** 제가 새 세션을 띄워 게이트 지시문을 그대로 넣고, 결과를 보여드립니다. **통과해야 다음 구간 촬영을 시작합니다.**
  - 사장님이 하실 일은 없습니다. 다만 **불합격이 나오면 원인이 「촬영」이 아니라 「제 반영」**이므로, 재촬영 요청이 아니라 문서 보강 보고를 드리게 됩니다
