# 판정 59 — 홈 (`/home`) · **만료 임박 영역 실측** (4-1 · 2026-09-16)

> 📎 `4-1_홈_크레딧바·만료임박·최근수정.jpg` · 원본 `4-1. 홈.mov` (21초)

## 경로 `cdbd.in/home`

| 영역 | 원문 |
|---|---|
| 인사 | **「안녕하세요, {이름}님」** + 그 아래 **이메일 칩**(👤 아이콘) |
| **크레딧 바** | **`크레딧 0 C │ 포인트 524,820 P`** + **[충전하기]** |
| **만료 임박** 📹 | **`6일 후 만료`**(주황) + **페이지명** + `https://www.cdbd.in/{내주소}/{슬러그}` + **[연장하기]** |
| 최근 작업 | **「가장 최근에 수정한 페이지에요」** — 썸네일 + 페이지명 + URL + **[이어서 작업하기]**(보라 풀폭) |
| 우측 | **[새 페이지 만들기]** · **[내 페이지 전체]** (아이콘 카드 2장) |

> ✅ **지시서 4번 확인** — *"7일 이내 만료 페이지가 있을 때만 뜸"* 전제가 맞았다. **6일 후 만료** 페이지가 있어 실제로 떴다.
> 🔑 만료 임박 줄은 **페이지당 1줄** 구조로 보인다(1건만 관측 · 다건일 때 목록인지 ⏳).

## 🔴 크레딧/포인트 표기 — 기존 「혼용 주의」를 뒷받침하는 증거

| 화면 | 표시 |
|---|---|
| 홈 크레딧 바 (17:25) | **크레딧 `0 C`** · 포인트 `524,820 P` |
| 권한 모달 「내 크레딧」 (17:38) | **`524,700C`** |

**같은 계정인데 홈은 「크레딧 0C」, 모달은 「내 크레딧 524,700C」다.** 모달 값은 홈의 **포인트** 값과 가깝다(차 120).
→ 기능 사전:323의 *"차감은 **포인트(P)** 에서 · 모달은 C 표기(혼용 주의)"* 를 **독립 관측으로 재확인.**
⏳ 120 차이가 그 사이 4-3·4-4 작업의 차감인지는 미검증.

## ⏳ 미확인
- 만료 임박이 **여러 건**일 때의 표시 (목록? 최대 몇 줄?)
- 크레딧이 0인데 권한 모달에선 52만이 보이는 **정확한 산식**
- 상단 우측 「CdBd 소식」·「문의하기」 내용

## 🔒 보안
홈에 **이메일 상시 노출** → 저장 프레임은 **마스킹**함.

# 🔴🔴 판정 60 — 권한 관리 · **「100C/자리·월」은 권한 1종 기준** · 실차감은 훨씬 크다 (4-5 · 2026-09-16)

> 📎 `4-5_팀원초대모달_권한3종·각100C월.jpg` · `4-5_크레딧계산_300C월×61일=600C.jpg` · `4-5_권한목록_태그3색·N명일괄메뉴.jpg` · `4-5_알림설정_토글2종.jpg`
> 원본 `4-5. 권한 관리.mov` (2분 7초) · ⚠️ **실제 차감 발생 촬영**

## 🎯 정본 정정 — 비용 구조가 문서보다 크다

| | 서술 |
|---|---|
| 지시서 💸 표 · `design-service:68` | *"권한 부여 **100C / 자리·월**"* |
| **실측** | 🔴 **권한이 3종이고 각각 100C/월이다.** 3종 다 주면 **300C/월/명** |
| 게다가 | 🔴 **이용 기간(URL 만료일까지)만큼 개월 단위로 곱한다** |

**실측 계산 화면 원문:**
> **1명의 팀원 초대 시 총 600 크레딧이 차감됩니다.**

| 항목 | 값 |
|---|---:|
| 팀원 수 | 1명 |
| **팀원 추가 금액** | **300C/월** |
| ∟ 페이지 편집 | 100C/월×1명 |
| ∟ 데이터 관리 | 100C/월×1명 |
| ∟ 통계 확인 | 100C/월×1명 |
| **이용 기간** | **61일** |
| **차감 예정 크레딧** | **600C** |

각주(원문):
- **「이용 기간: URL 만료일까지 남은 기간」**
- **「팀원 초대 크레딧은 1개월 단위로 차감 (ex. 이용 기간 40일이면 2개월 차감)」**

> ⚠️ **개월 환산 규칙은 미확정.** 실측 쌍은 **61일 → 2개월(600C)** 이고 각주 예시는 **40일 → 2개월**이다. 30일 기준이면 61일은 3개월이어야 하므로 **30일 기준이 아니다.** 31일 기준이면 둘 다 2개월로 맞지만 **관측 2건뿐이라 단정하지 않는다.**
> 🔑 **실무 영향** — *"권한 하나 주면 100C"* 로 알고 있으면 **실제 청구가 6배**가 될 수 있다(3권한 × 2개월).

## 권한 3종 (원문)

| 권한 | 비용 | 설명 |
|---|---|---|
| **페이지 편집** | 팀원 당 100 크레딧/월 | 「페이지를 수정하거나 복제해서 사용할 수 있습니다.」 |
| **데이터 관리** | 팀원 당 100 크레딧/월 | 「데이터를 편집 및 다운로드할 수 있습니다.」 |
| **통계 확인** | 팀원 당 100 크레딧/월 | 「통계 데이터를 확인 및 다운로드할 수 있습니다.」 |

각 권한은 **토글**이며 기본 **전부 ON**(관측). 토글을 끄면 그만큼 금액이 빠진다.

  (관측: 초대 전 `1/1`→`1/2`→`2/2`, 권한 삭제 후 **`페이지 0/2`** 로 떨어짐)

# 🔴🔴 판정 61 — 복사본 공유 · **「초대받은 페이지」가 아니다** · **비가역 경고가 화면에 없다** (4-4 · 2026-09-16)

> 원본 `4-4. 복사본 공유.mov` (1분 2초) · 계정 2개 · ⚠️ **취소 불가 기능 실제 수행**

## 🔑 경로 — `내 페이지`가 `/editor`다 (혼동 주의)

| 화면 | URL |
|---|---|
| **내 페이지 (목록)** | 🔴 **`cdbd.in/editor`** (+ `?refresh={ts}`) — **에디터가 아니라 목록이다** |
| 초대받은 페이지 | **`cdbd.in/invited`** |
| 복사본 편집 | `cdbd.in/editor/{id}` |

> ⚠️ **`/editor` 하나가 「목록」과 「에디터」 둘 다**에 쓰인다(뒤에 id가 붙으면 에디터). 자동화·문서에서 혼동하기 쉬움.

## 페이지 카드 ⋯ 메뉴 — **7항목 · 4그룹** (구분선 포함)

| 그룹 | 항목 |
|---|---|
| 1 | 「복제하기」 · 「삭제하기」 |
| 2 | **「복사본 공유하기」** |
| 3 | 🔣 「데이터 관리하기」 · 👤+ 「권한 관리하기」 *(이 둘만 아이콘 있음)* |
| 4 | 「버전 히스토리 보기」 · 「URL 게시 중지하기」 |

## 「복사본 공유하기」 모달 (원문)

- 안내 **「{페이지명} 페이지의 복사본을 편집 가능한 형태로 공유합니다.」**
- **「CdBd 계정」** + **「N명 추가됨」**
- placeholder **「이메일 계정을 입력해 주세요.」** + **[추가]** → 추가 시 **칩(`이메일 ✕`)으로 아래 박스에 쌓임**
- 에러 **「✕ 이메일 주소를 정확히 입력해 주세요.」**
- **[취소하기] / [공유하기]** (0명이면 비활성)

**실행 → 완료**
1. [공유하기] → 버튼 스피너
2. 같은 자리에 완료 화면 — ✅ + **「1명 에게 공유 메일 전송됨」** + **[확인하기]**
3. 닫으면 초록 토스트 **「복사본 공유가 완료되었습니다.」**

## 🔴 발견 ① — **비가역 경고가 화면에 없다**

> 볼트·지시서: *"⚠️ 복사본 공유 — **취소 불가**"* · *"실제 고객에게 복사본 공유 — 취소 불가"*

**모달 전 구간(4fps 재스캔)에 「취소 불가」·「되돌릴 수 없」·「철회」 류 문구가 없다.**
**2차 확인 다이얼로그도 없다** — [공유하기] 누르면 즉시 전송된다.
안내문은 **「편집 가능한 형태로 공유합니다.」**가 전부.

→ 🔑 **제품 동작이 비가역이더라도 사용자에게 경고되지 않는다.** 볼트의 「취소 불가」는 **우리 운영 지식이지 화면 근거가 아니다** — 출처를 그렇게 표시해야 한다.

## 🔴 발견 ② — **지시서 4-4 ④번 전제가 틀렸다**

> 지시서: *"수신 계정 → 내 페이지 → **「초대받은 페이지」 탭** → 받은 페이지 확인"*

**실측 — 「초대받은 페이지」(`/invited`)에 복사본이 없다.**
복사본은 **「내가 만든 페이지」**에 들어온다. 카드에 **소유자 표기 없음 · 발행 URL/QR/만료일 없음(미발행)**.

| 기능 | 결과물 위치 | 성격 |
|---|---|---|
| **복사본 공유** | **「내가 만든 페이지」** | **수신자 소유의 독립 새 페이지** |
| **권한 관리(초대)** | **「초대받은 페이지」** | 원본에 대한 **권한 부여**(소유자 표기 있음) |

## 페이지네이션 — **페이지당 6개 (3열×2행)**

## 🎯 결론 — **헤더 카운터의 「분모(구매 자리)」가 과금을 가른다**

영상에 **과금되는 초대**와 **무과금 초대**가 **한 클립에 나란히** 담겼다.

| 회차 | 초대 직전 카운터 | 계산 모달 | 차감 | 초대 후 카운터 |
|---|---|---|---|---|
| **1차** | **`1/1`** (자리 다 참) | ✅ **뜸 — 600C** | **−600C** | `2/2` |
| **2차** | **`1/2`** (삭제로 자리 1개 빔) | ❌ **아예 안 뜸** | **0C** | `2/2` |

### 산술 검증
| 시점 | 잔액 |
|---|---:|
| 1차 계산 모달 「내 크레딧」 | **521,900C** |
| 1차 초대 직후 내 계정 | **521,300P** = 521,900 − **600** ✅ |
| **2차 초대 직후 내 계정** | **521,300P** — **변화 없음** ✅ |

> 🔑 **자리(구매 슬롯)가 남아 있으면 재초대는 공짜다.** 계산 모달이 **뜨지도 않고** 바로 「1명에게 초대 메일 전송됨」으로 끝난다.
> 🔑 **자리가 부족할 때만** 계산 모달이 뜨고 **새 자리를 구매**한다.
> → 판정 62에서 *"삭제해도 분모가 유지된다"* 고 관측한 것의 의미가 밝혀졌다 — **분모 = 이미 사 둔 자리 수**이고, **기간 내에는 재사용할 수 있다.**

### 💰 실무 영향 (큼)
- **팀원 교체는 무료다** — A를 빼고 B를 넣는 건 추가 비용이 없다
- **비용은 「동시 최대 인원」에 붙는다** — 누적 초대 횟수가 아니라 **피크 자리 수**
- ⏳ 자리가 **URL 만료일과 함께 소멸**하는지, 만료 후 재초대 시 다시 과금인지는 **미검증**
