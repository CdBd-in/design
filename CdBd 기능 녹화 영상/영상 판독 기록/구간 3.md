# 🔴 판정 48 — 이메일 가입 · **비밀번호 조건은 4개, 「소문자」가 없다**

> 📎 `3-1_*.jpg` (5장)

## 🎯 정본 오류 — 사전의 「대·소문자」가 틀렸다

기능 사전: *"회원 가입 — Google · Apple · 이메일. 비번 = **9자↑ 대·소문자·숫자·특수기호 각 1**"*

**실측 조건 목록 = 4줄뿐:**

| # | 문구 (원문) |
|---|---|
| 1 | **9자 이상이어야 합니다.** |
| 2 | **대문자가 하나 이상 있어야 합니다.** |
| 3 | **숫자가 하나 이상 있어야 합니다.** |
| 4 | **기호가 하나 이상 있어야 합니다.** |

> ✅ **「9자 이상」은 맞았다**(촬영 지시서가 「8자」로 적은 것이 오히려 오류).
> ❌ **「소문자」 조건은 존재하지 않는다.** 화면에 그 줄 자체가 없다.
> → 사전을 **「9자↑ · 대문자 · 숫자 · 기호 각 1」**로 정정.
> ⏳ 소문자 **없는** 비번(`!!KANG6624`)이 실제로 통과하는지는 미검증 — 조건 목록에 없으니 통과할 것으로 추정.

## 이메일 유효성 상태 4종 (원문)

| 상태 | 문구 | 표시 |
|---|---|---|
| 형식 오류 | **「이메일 형식이 아닙니다.」** | ✕ 빨강 · 입력란 빨간 테두리 |
| 중복 | **「이미 가입된 이메…」** | ✕ 빨강 |
| 검사 중 | **「이메일 중복 검사 중...」** | ✕ 빨강 (⚠️ **진행 중인데 오류색**) |
| 통과 | **「가입 가능한 이메일입니다.」** | ✓ 파랑 |

> 🔑 **「중복 검사 중...」이 ✕ 빨강으로 뜬다** — 진행 상태인데 오류처럼 보인다. 팀원이 오해할 수 있음.

## 가입 후 흐름

1. **✓ 인증 메일 전송됨** — *"{이메일}로 인증 메일을 보냈습니다. 이메일을 확인하고 링크를 클릭해 인증을 완료해 주세요."*
2. 메일함 → 인증 링크 (본문에 *"…브라우저에 붙…"* 대체 링크 + `pkce_` 토큰)
3. **✓ 인증 완료!** → **「어떻게 불러드릴까요?」** · **이름** 입력란
4. 버튼 **2개** — **[시작하기]**(보라 · 주) / **[나중에 입력하기]**(흰 · 보조)

> ✅ 지시서 3-1의 1~5번 **전부 충족.**

## ⚠️ 보안 — 이 영상은 볼트에 프레임 저장 시 구간 선별 필요

- **브라우저 비밀번호 자동완성 드롭다운**이 여러 번 열려 **계정 이메일 5개가 평문 노출**(30초·12초·36초 등)
- **비밀번호 입력란이 평문 표시**된 구간 있음(👁 토글 ON)
- **Chrome 프로필 메뉴**에 계정 정보 노출(90초)
→ **위 구간을 피한 5장만 저장함.** 앞으로 계정 화면 촬영 시 **자동완성 드롭다운을 닫고** 찍을 것.

## ⏳ 미확인
- 소문자 없는 비번이 실제 통과하는지
- 「이미 가입된 이메일입니다」 전문(잘림)
- 인증 메일 유효 시간·재전송

# 🔴 판정 51 — 온보딩 = **소속에 따라 단계 수가 달라진다** (3-4,5 · 2026-09-16)

> 📎 `3-4,5_소속3종_기업·개인·학생.jpg` · `3-4_기업_규모4·업종8.jpg` · `3-4_직무8종·제목이업종연동.jpg` · `3-4_서비스10종+없음·5단계표시.jpg` · `3-4_매거진_기본ON·완료버튼.jpg` · `3-5_개인_서비스선택·단계표시없음.jpg` · `3-4,5_완료후_템플릿화면_cdbd.in-templates.jpg`
> **원본** `3-4,5. 온보딩.mov` · **1분 4초** (3-4와 3-5를 한 클립에 합쳐 촬영)
> ⚠️ **기존 정본에 온보딩 서술이 아예 없었다** (`CdBd 기능 목록.md:126` = *"○ 없음"*). 이 판정이 **최초 기록**이다.

## 🎯 핵심 — 경로는 `cdbd.in/onboarding`, 단계는 **URL 쿼리로 노출**된다

| 화면 | 기업 | 개인 | 학생 |
|---|---|---|---|
| 1. 소속 선택 | `/onboarding` | `/onboarding` | `/onboarding` |
| 2. 규모 + 업종 | `?stage=2&group=company` | — (없음) | — (없음) |
| 3. 직무 | `?stage=3&group=company` | — (없음) | — (없음) |
| 4. 서비스 선택 | `?stage=4&group=company` | **`?stage=2&group=personal`** | **`?stage=2&group=student`** |
| 5. 매거진 구독 | `?stage=5&group=company` | **`?stage=5&group=personal`** | (미도달) |

> 🔑 **`group` 값 3종 = `company` · `personal` · `student`** (실측 URL 원문).
> 🔑 **기업 = 5화면 / 개인·학생 = 3화면.** 개인·학생은 **stage 2 → 5로 건너뛴다** — 즉 `stage=5`(매거진)는 **마지막 단계로 고정**돼 있고, 중간 단계만 빠진다.

## 🔴 단계 표시(스텝 인디케이터)는 **기업에만 뜬다**

- **기업** — 모달 위에 **꽃 아이콘 5개 + 연결선**. 완료=흰 꽃 / 현재=보라 꽃 / 미도달=회색 점. `stage=2`면 2번째까지 보라.
- **개인·학생** — ⛔ **인디케이터가 아예 렌더되지 않는다.** (같은 위치를 2~3군데 크롭해 재확인 — 없음)

> ⚠️ 지시서 3-5의 *"단계가 몇 개로 줄어드는지"* 에 대한 답 = **줄어드는 게 아니라 표시 자체가 사라진다.**

## 화면별 실측 (원문)

### ① 소속 — `소속을 알려주세요`
상단에 **CardBoard 로고 + 「{이름}님 반갑습니다!」**
선택지 **3종 (아이콘+칩)** — **기업**(빌딩) / **개인**(사람) / **학생**(책)
- 선택하면 아이콘이 **보라로 반전 + 우상단 ✓ 배지**, 칩도 보라 채움
- 이 화면에만 **← 뒤로 버튼이 없다** (2단계부터 `←` + `[다음]` 2버튼)

### ② 기업 — `어떤 기업에 다니고 계신가요?` (한 화면에 질문 2개)
**❶ 어느 정도 규모의 기업인가요?** — `5인 미만` · `5~29인` · `30~199인` · `200인 이상` **(4종)**
**❷ 어떤 일을 하는 기업인가요?** — `IT` · `제조 · 유통` · `광고 · 마케팅` · `예술 · 디자인` · `비영리 · 교육` · `금융 · 보험` · `의료 · 제약` · **`기타 (직접 입력)`** **(8종)**

> 🔑 답을 고르면 **질문 앞의 번호 뱃지 ❶❷ 가 ✓ 로 바뀐다.**

### ③ 기업 — 직무 · **제목이 ②의 업종을 그대로 받는다**
제목 원문: **「광고 · 마케팅 회사에서 / 어떤 일을 하시나요?」** ← `광고 · 마케팅`은 ②에서 고른 값
선택지 **8종** — `마케팅` · `영업` · `디자인` · `전략 기획` · `고객 관리` · `인사` · `대표 · 임원` · **`기타 (직접 입력)`**

### ④ 서비스 — `이용해 본 적 있는 서비스를 / 모두 선택해 주세요`
부제 **「복수 선택이 가능해요」**
선택지 **10종 + 「없음」** — `노션` · `리틀리` · `링크트리` · `미리캔버스` · `아임웹` · `워드프레스` · `윅스` · `캔바` · `포토샵` · **`없음`**
- 각 칩에 **서비스 로고**가 붙는다 (없음만 로고 없음)
- 선택 = **왼쪽에 보라 ✓ 원 + 보라 배경**. 호버 = 연보라 테두리만 (✓ 없음) — **두 상태가 비슷해 혼동 주의**

### ⑤ 매거진 — `CdBd 매거진을 구독하고 / 페이지 제작 꿀팁과 활용 사례를 / 가장 먼저 받아보세요!`
버튼 **2개 (택1 토글)** — `다음에 할게요` / **`네, 받아볼게요`**
- 🔴 **화면이 뜨는 순간 「네, 받아볼게요」가 이미 선택돼 있다 = 구독 기본 ON** (32.0초 최초 렌더 프레임에서 확인)
