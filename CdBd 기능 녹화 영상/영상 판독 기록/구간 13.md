# 판정 186 — 질문과 답변: 필수 누락은 토스트 하나 · 형식 검사 없음 · 다시 제출 가능 (13-1)

> 📎 `13-1_파일받기모달·제출완료·필수누락.jpg`

- 아무것도 안 넣고 [제출] → 버튼 위 빨간 토스트 「**필수 질문에 답변해주세요.**」 — 🔑 **어느 질문이 비었는지 표시하지 않고 스크롤도 하지 않는다**(13-1·13-2 t3~6)
- 복수 선택(isMultiple) 질문 = 체크박스 · 3개 모두 선택된다(t12~16)
- 「전화번호」 칸에 `Abc` → 그대로 통과(13-1·13-2 t17~27) — 🔑 **전화번호 질문도 주관식이라 형식 검사가 없다**(상담 신청서 프리셋의 한계 · 숫자 키보드도 아님)
- 폰 키보드가 입력란을 가리지 않았다 — 사파리가 입력 중인 칸을 위로 올린다
- 제출 성공 → **폼 자리가 회색 상자로 바뀜**: 하트 편지 아이콘 + 「**답변이 제출되었습니다.**」 · [제출] 사라짐 (13-1 t26~29)
- 🔑 **새로고침하면 빈 폼이 다시 나오고, 다시 제출된다**(13-1 → 13-1·13-2에서 같은 폰으로 두 번째 제출 성공) — 1인 1회 제한 없음
- ⏳ PC 통계 「제출된 답변」 건수(지시서 9번) · 바로 한 번 더 누르기(7번 — 제출 직후 버튼이 없어 시도 불가)

# 판정 187 — 🆕 「이메일로 파일 받기」 = 제출 후 동작 · 이메일로 다운로드 링크가 간다 (13-1)

> 📎 `13-1_파일공유_메일본문.jpg`

- 질문과 답변 카드에 **「제출 후 동작 = 이메일로 파일 받기」**를 켜 두면, 필수를 다 채우고 [제출]을 누를 때 모달 「**이메일로 파일 받기** / 파일을 받을 이메일 주소를 입력해 주세요. / 이메일 [ ] / [취소하기][확인하기]」가 먼저 뜬다 (13-1 t19)
  - 형식이 틀리면 칸 아래 빨간 「**이메일 주소를 정확히 입력해 주세요.**」(13-1·13-2 t32~41)
- [확인하기] → 「답변이 제출되었습니다.」 + 초록 토스트 「**이메일이 발송되었습니다.**」(t26~28)
- 메일(보낸사람 `CdBd <noreply@cdbd.in>` · 제출 1분 안 도착) = 제목 「**{페이지 제목}에서 파일을 공유받았습니다.**」 · 본문 「{페이지}에서 {파일명} 파일을 공유받았습니다. 아래 버튼을 눌러 파일을 내려받아 주세요.」 + **[파일 내려받기]** + 「버튼이 작동하지 않는 경우…」 아래에 **Supabase 서명 URL 전문**(`…/user_assets/…/link-file/6874/….png?token=…&download=…`) (13-1·13-2 t52~58)
- [파일 내려받기] → 사파리 「'기억의 전람회 콘서트 프로그램.png'을(를) 다운로드하시겠습니까? 보기 · 다운로드」 → 다운로드 목록 → 이미지 열림 (t59~69)
- 🔑 사전에 없던 기능 — 「신청하면 자료를 메일로 보내 주는 폼」을 만들 수 있다 · ⏳ 편집기의 설정 화면(제출 후 동작의 다른 선택지)은 이 영상에 없다

# 판정 188 — 페이지 상단 메뉴(모바일) = 오른쪽 위 ⋯ 버튼 → 「구독하기 · 저장하기 · 공유하기」 세로 알약 (13-5)

> 📎 `13-3·13-5_상단메뉴·전화·문자 확인창.jpg`

- 「상단 메뉴」라는 이름과 달리 **가로 막대가 아니다** — 오른쪽 위 원형 **⋯** 버튼 하나 → 누르면 ✕로 바뀌고 아래로 흰 알약 3개 「🔔 구독하기」「♡ 저장하기」「⤴ 공유하기」 (13-3·13-5 t0~2)
- 🔑 **스크롤해도 같은 자리에 떠 있다**(고정) — 펼친 채로 페이지를 내려도 콘텐츠 위에 겹친다

- 🔁 구간 6의 「모바일 뷰어의 상단 메뉴 형태 ⏳」 → 확정

| L3 문자 보내기 | 사파리 확인창 「**'메시지'에서 이 페이지를 열겠습니까?** 취소 · 열기」 → 메시지 앱 · 받는 사람 = 설정 번호(연락처 이름으로 표시) · 🔑 **본문에 기본 문구 「안녕하세요」가 채워진다**(t11~19) |

# 판정 190 — 위치 안내: 구글 지도는 두 손가락으로만 움직인다 · [지도 보기] → 지도 앱 (13-4)

- 구글맵 카드 = 지도 위 한 손가락 드래그 → 지도는 그대로, 어두운 막 + 「**지도를 움직이려면 두 손가락을 사용하세요.**」 → 페이지가 스크롤된다(t2~6)
- 지도 아래 = 주소 텍스트 + **[지도 보기]** (☑ 주소 표시 · ☑ 버튼)
- 구글 [지도 보기] → **Google Maps 앱**이 열리고 그 주소의 장소 카드(경로 · 시작 · 공유)(t11~14)
- 네이버맵 카드 = 정적 지도처럼 보임 · [지도 보기] → 사파리 `map.naver.com` → **네이버 지도 앱 실행**(앱 스플래시 광고 → 장소) → 사파리로 돌아오면 `map.naver.com` 「네이버지도 앱 설치 / 네이버지도 앱 열기」 페이지가 남는다(t29~42)
- ⏳ 지도 앱이 없는 폰 · Android

# 판정 191 — 갤러리·이미지 확대 보기 (13-9)

- 갤러리(넘겨보기) = 좌우 **‹ › 화살표** + 아래 점 내비게이션 · 자동 넘김 3초로 저절로 넘어감 · 손가락 스와이프로도 넘어감(t43~70)

- ◐ 핀치 동작 자체(손가락)는 화면 기록에 보이지 않아 결과 화면으로만 판단

# 판정 192 — 유튜브: 무음 자동재생이 꺼져 있으면 정지 상태 · 누르면 인라인 재생 · 전체화면은 iOS 플레이어 (13-10)
