# 🚨 판정 96 먼저 — **계정 삭제가 「요청」됐다** (9-6 · 2026-09-18)

> 📎 `9-6_계정삭제_1단계_이탈사유설문.jpg` · `9-6_계정삭제_2단계_「영구 삭제됩니다」.jpg` · `9-6_🚨실제요청됨_「확인 후 7일 이내에 처리됩니다」.jpg`

## 🚨 지시서가 금지한 「완료」까지 진행됐다

> 지시서 9-6: *"⚠️ **완료 금지** … 취소하고 나오기"*

**대상 계정 = `0703cute34@gmail.com` (2026.09.16 가입)** — 테스트 계정이다. 그러나 **[계정 삭제하기]가 실제로 눌렸고** 브라우저 알림이 떴다:

> **「계정 삭제가 요청되었습니다. 확인 후 7일 이내에 처리됩니다.」** + [확인]

> 🔑 **즉시 삭제가 아니라 「요청 → 7일 이내 처리」다.** 이 사실 자체는 **매우 가치 있는 실측**이다(어느 정본에도 없었다).
> 🚨 **그러나 이 계정은 앞으로도 쓸 계획이 있었다** — 구간 6-1 Google 로그인 계정이고, **9-5b(미연동 스마트스토어 연동 정보)** 촬영 후보였다.
> ⚠️ **7일 안에 필요한 촬영을 끝내거나, 삭제 요청을 취소해야 한다.** ⏳ **취소 방법은 확인되지 않았다**(재로그인으로 철회되는지 불명).

## 2단계 구조

| 단계 | 내용 |
|---|---|
| **① 이탈 사유 설문** | 「계정 삭제 이유를 알려주시면 제품 개선에 활용할게요.」 / 「복수 선택이 가능해요」<br>체크박스 5 — **다른 계정으로 이용할게요 / 에디터 사용이 불편해요 / 원하는 기능이 없어요 / 잘 사용하지 않아요 / 기타 (직접 입력)**<br>입력란 「계정 삭제 이유를 알려주세요.」 · [취소하기] / [계정 삭제하기] |
| **② 최종 경고** | 「**제작한 페이지와 관련 데이터가 영구 삭제됩니다. 정말로 계정을 삭제하시겠습니까?**」 · [취소하기] / [계정 삭제하기] |
| **③ 브라우저 알림** | 「계정 삭제가 요청되었습니다. **확인 후 7일 이내에 처리됩니다.**」 |

> 🔑 **확인 문자열(「DELETE」 등)을 타이핑하는 단계는 없다.** 체크박스만 고르면 2단계로 넘어간다 — **오클릭 방어가 약하다.**
> 🔑 **1단계에 경고 문구가 없다**(설문뿐). 지시서 ②가 요구한 「경고 문구 전문」은 **2단계에 있다.**

## 「크레딧 결제 내역」 (충전 이력)

| 컬럼 | 비고 |
|---|---|
| **구분 · 일시 · 내용 · 금액** | 🔑 **금액 헤더에 「*부가세 포함」 각주** |
| **[엑셀 다운로드]** | |

실측 1행 — `2026.02.04 10:43 / 1000000C / ₩100,000`
> ⚠️ **1,000,000C = ₩100,000이면 1C = 0.1원**이다. 공식 요금표(**1C = 100원**)와 **1000배 차이**.
> → **정상 구매가 아니라 사내 지급/테스트 충전**으로 보인다(잔액 87만C과 정합). ⏳ **단정하지 않는다.**

# 💰 판정 92 — 🔑 **개별 URL에도 「자리」가 있다. 재생성은 0C** (9-2 · 2026-09-18)

> 📎 `9-2_개별URL_재생성_0C_자리재사용.jpg`

## 데이터 버전 히스토리

**진입 = 데이터 관리 화면 우상단 🕐 아이콘** (지시서 9-2 ① 답 · 보충 목록 A5도 동시 해소)

| 항목 | 에디터용(9-1)과의 차이 |
|---|---|
| 좌측 | 버전 목록 — 동일 구조 |
| **우측 미리보기** | 🔑 **폰 렌더가 아니라 「데이터 테이블」**이 뜬다 |
| 복구 | **「데이터 버전 복구하기」** 확인 모달 → **「데이터 버전 복구 완료」** |

## 🚨 복구하면 **개별 URL이 사라진다**

복구 후 데이터 관리 화면에서 **「CdBd URL」 열이 비었고** 헤더가 **`개별 URL 0개 이용중 / 총 3개`** 로 바뀌었다.
> 🔑 복구는 **그 시점의 데이터로 되돌리므로**, 복구 시점 이후에 만든 개별 URL이 **날아간다.**

## 🎯 그런데 재생성이 **0C다**

> 「**2개**의 개별 URL 생성 시 / 총 **0 크레딧**이 차감됩니다.」
> 개별 URL 수 **2개** · 이용 기간 **30일** · **차감 예정 크레딧 `0C`** (각주는 동일: 1개당 1개월 5C)

> 🔑 **헤더의 `0개 이용중 / 총 3개`가 답이다** — **이미 3자리를 사뒀고, 지금 0개만 쓰는 중**이라 **2개 재생성이 무과금**이다.
> 🎯 **권한 관리의 「자리 재사용 무과금」(판정 65)과 완전히 같은 패턴.** 개별 URL도 **「자리(quota)」 개념**으로 과금된다.
> 🔴 **판정 83을 보강해야 한다** — 「300개면 1,500C」가 아니라 **「이미 산 자리를 빼고」** 계산해야 한다.
> ⏳ **자리가 언제 반납되는지**(삭제 시? 만료 시?) · 자리보다 **많이** 만들 때 차액만 과금되는지 미확정.
