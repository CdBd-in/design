# 🔴🔴 판정 105 — 「대체어」는 **기본값이 아니다** (1-1 · 정본 오류)

> 📎 `동선3/t0054.0.jpg` · `t0070.0.jpg` · `t0100.0.jpg` (셋 다 직접 대조 확인)

**사전 서술** — *「대체어 = 값이 없을 때 쓰는 기본값」* → 🔴 **오류.**

## 3단 비교로 확정

| 조건 | 화면 | 결과 |
|---|---|---|
| **기본 뷰어** (개별 URL 아님) `editor/6339/viewer` | 「일시**성함**」 · 「2026년 6월 24일 화요일**전화번호**」 · 「Summit**성함**」 | **대체어가 찍힌다** |
| **개별 URL** `mustard73/dateste/ALC` | 「일시**김재인**」 · 「…화요일**010-1234-5678**」 | **실제 값이 이긴다** |
| 🔑 **개별 URL + 셀을 비움** | 「2026년 6월 24일 화요일」 **뒤에 아무것도 없음** | 🔴 **대체어가 안 나온다** |

> 🎯 **참값** — **대체어 = 「개별 URL이 아닌 기본 페이지로 접근했을 때 변수 자리에 대신 찍히는 문자열」.**
> **개별 URL의 빈 셀은 대체어로 채워지지 않고 공백으로 렌더된다.**
>
> 🔑 **실무 함의** — *"값이 비면 대체어가 나오니 안심하세요"* 라고 안내하면 **틀린다.** 개별 URL을 받은 고객은 **빈칸을 그대로 본다.**

## 부수 확인 — 「표시용 이름 바꾸기」도 아니다
- 테이블 헤더는 저장 후에도 「ex. 이름」 / 「ex. 휴대폰 번호」 그대로 (`t0082.0.jpg`)
- 에디터 변수 삽입 메뉴도 「CdBd URL / ex. 이름 / ex. 휴대폰 번호 / 데이터 관리하기」 그대로 (`t0016.0.jpg`)
- 캔버스 토큰도 「일시 `$$ex. 이름$$`」 그대로 (`t0018.0.jpg`) → ✅ **`$$열이름$$` 문법 재확인**(자동화 자산 점검 항목)

## ⏳ 남은 것
- **「대체어 ⓘ」 툴팁 원문** — 호버 프레임이 한 장도 없다. **미확인**
- 대체어 입력 **이전**에 기본 뷰어가 무엇을 보여줬는지(열 이름? 공백?) — 프레임 없음

# 🔑 판정 109 — ⚙ 「페이지 설정」은 **문서 전역**이다 (4-3)

> 📎 `동선2/t0100.0.jpg` · `t0120.0.jpg` · `t0122.0.jpg` · `t0200.0.jpg`
