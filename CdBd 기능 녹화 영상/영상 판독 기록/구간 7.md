# 판정 79 — 데이터 관리 = **`cdbd.in/data/{id}`** · 🔑 **「대체어」는 헤더 아래 전용 행** (7-1 · 2026-09-18)

> 📎 `7-1_데이터관리_빈상태_「고객별 데이터가 들어간」.jpg` · `7-1_테이블구조_구분+대체어행+열헤더아이콘3종.jpg`

## 경로·헤더

**URL = `cdbd.in/data/{editorId}`** (에디터 `cdbd.in/editor/{id}`와 **id가 다르다** — 6336·6337·6339 등 별도 채번)

| 영역 | 내용 |
|---|---|
| 제목 | **「{페이지명} 데이터 관리하기」** |
| 부제 | `URL 생성 {날짜 시각}` · `URL 만료 {날짜} (N일 남음)` · 🔑 **`개별 URL N개 이용중 / 총 N개`** |
| 우측 | **🕐**(이력) · **[에디터 바로가기]** · **[개별 URL 생성하기]**(검정) · **[변경사항 저장하기]**(보라 · 🔑 **변경 전엔 비활성**) |
| 좌측 툴바 | **[데이터 추가 ⌄]** · **[데이터 다운로드]** |
| 우측 툴바 | 검색 — placeholder **「검색어를 입력하세요」** |

> 🔑 **자동저장이 아니다.** 에디터와 달리 **[변경사항 저장하기]를 눌러야 커밋**된다(변경 발생 시 보라로 활성화).

## 빈 상태 (데이터 없을 때)

> 「**고객별 데이터**가 들어간 / 페이지를 만들어 전환율을 높여 보세요!」
> 예시 카드 2개(**김재인 고객님 2,000원** / **박현수 고객님 5,000원** — 쿠폰 형태) + **[자세히 알아보기]** / **[데이터 생성하기]**(보라)

## 🎯 테이블 구조 — 3층이다

| 층 | 내용 |
|---|---|
| **① 열 헤더** | 열 이름(기본값 **`ex. 이름`** · **`ex. 휴대폰 번호`**) + 🔑 **우측 아이콘 3종 = ⬆(업로드) · 🖼(이미지 연결) · 🗑(열 삭제)** |
| **② 「대체어」 행** | 🔑 **헤더 바로 아래 전용 행.** 좌측에 **「대체어 ⓘ」** 라벨 · 각 열 칸에 **「⇄ 대체어 추가하기」** |
| **③ 데이터 행** | 좌측 **「구분」** 열에 행 번호(1, 2, …) |

> 🔑 **「대체어」는 셀이 아니라 「열마다 하나씩 붙는 별도 행」이다.** 지시서 7-1 ⑤의 *"어디에 입력하는지"* 에 대한 답.
> ⏳ **「대체어 ⓘ」 툴팁 원문은 미확인**(호버하지 않음) — 지시서가 명시적으로 요구한 항목이라 **미충족**.

## 지시서 7-1 대비 충족도
| # | 지시서 | 결과 |
|---|---|---|
| ① | 초기 화면·빈 상태 | ✅ |
| ② | 행 추가·열 추가·열 이름 수정 | ✅ |
| ③ | 셀 클릭 → 편집 | ✅ (셀 테두리 강조) |
| ④ | 행 삭제·열 삭제 | ✅ **「데이터 행 삭제하기」 확인 모달** 확인 · 열 삭제는 헤더 🗑 |
| ⑤ | **대체어 + ⓘ 툴팁** | ◐ **위치는 확보 · 🔴 툴팁 원문 미확인** |
| ⑥ | **검색 → 일치 문자 강조** | 🔴 **미실행** — 검색창 존재만 확인 |
| ⑦ | 50행 페이지네이션 | 🔴 **미실행** (실측 최대 2행) |

## ⏳ 미확인
- **대체어 ⓘ 툴팁 원문**과 **대체어가 실제로 무엇을 바꾸는지**(뷰어 표시? 엑셀 양식 헤더?)
- **검색 동작·하이라이트** · **페이지네이션**(50행 기준 진위)
- 열 **최대 개수** · 행 **최대 개수**
- [데이터 다운로드] 결과 파일 구조

# 판정 80 — 엑셀 업로드 = **열 매칭 화면이 없다. 「양식 다운로드 → 채워서 업로드」** (7-2 · 2026-09-18)

> 📎 `7-2_엑셀로데이터추가하기_모달전문_양식다운로드.jpg`

## 「엑셀로 데이터 추가하기」 모달 전문

| 영역 | 원문 |
|---|---|
| 제목 | **「엑셀로 데이터 추가하기」** + ✕ |
| 업로드 | **「파일 업로드하기」** / **「XLS, XLSX, XLSM, CSV 파일을 업로드해 주세요.」** |
| 드롭존 | **「이 곳을 클릭하거나 파일을 끌어오세요」** |
| 안내 박스 | **「양식에 맞는 파일을 업로드해 주세요!」**<br>**①** 「먼저 데이터 관리 페이지에서 **열을 추가하고 데이터 그룹명을 입력**해 주세요.」<br>**②** 「아래에서 **엑셀 양식을 다운로드**하고 데이터를 작성한 후 파일을 업로드해 주세요.」 |
| 버튼 | **[⬇ 엑셀 양식 다운로드]** |
| ⓘ 4줄 | 🔑 「입력된 데이터를 **덮어쓰지 않고 다음 순서로 추가**됩니다.」<br>「양식이 일치하지 않는 경우 데이터가 추가되지 않습니다.」<br>「데이터 그룹을 편집한 경우 **양식을 다시 다운로드** 해야 합니다.」<br>「자세한 내용은 **CdBd 가이드센터**를 참고해 주세요.」 |
| 하단 | [취소하기] / [데이터 추가하기] |

> 🔴 **지시서 7-2 ②「열 매칭 화면이 있는지」의 답 = 없다.** 매칭 UI 대신 **제품이 내려준 양식(`CdBd_데이터_양식.xlsx`)을 그대로 채워 올리는** 방식이다.
> 🚨 **실무 함정 3개**
> 1. **열을 먼저 만들고 → 양식을 받아야 한다.** 순서를 바꾸면 양식에 열이 없다
> 2. **열을 고친 뒤엔 양식을 다시 받아야 한다** (옛 양식은 불일치로 거부)
> 3. **업로드는 덮어쓰기가 아니라 「이어붙이기」** — 같은 파일을 두 번 올리면 **행이 중복된다**
> 🔑 **지원 포맷 4종 = XLS · XLSX · XLSM · CSV**

## ⏳ 미확인
- 양식 파일의 **실제 열 구성**(헤더 행 형태) · 대체어가 양식에 반영되는지
- **불일치 업로드 시 에러 문구** · 부분 성공 여부
- [데이터 다운로드] 결과가 양식과 동일한지

# 판정 81 — 이미지 연결 = **「파일 업로드」 / 「URL로 연결」 2방식** (7-3 · 2026-09-18)

## 진입
열 헤더의 **🖼 아이콘** → **「이미지 연결하기」 모달** — *"이미지를 어떤 방법으로 연결할까요?"*

| 방식 | 설명 |
|---|---|
| **파일 업로드** | 데이터에 입력된 값과 **파일명이 일치**하는 이미지를 업로드 → 자동 매칭 |
| **URL로 연결** | 데이터에 이미지가 저장된 **URL을 직접 입력** |

**URL 방식 서브모달** — 「이미지를 성공적으로 불러오기 위해 입력한 URL을 확인해 주세요」 + **「지원되는 URL」 / 「지원되지 않는 URL」** 안내 2블록

> ✅ 실측 — 파일 업로드 2장 → 테이블 셀에 **파일 경로 문자열**(`file:///Users/.../Desktop/…`)이 들어갔다.
> 🚨 **이게 그대로 뷰어에 텍스트로 노출됐다**(7-4 48초) — **로컬 경로가 값으로 들어가면 이미지가 아니라 경로 문자열이 찍힌다.**
> ⏳ **정상 연결 시 「배지」가 어떻게 표시되는지**(지시서 7-3 ④)는 **확정하지 못했다** — 에디터 카드 우상단의 주황 🔗 배지가 후보지만 데이터 연결 배지인지 링크 연결 배지인지 구분되지 않는다.

## ⏳ 미확인
- **배지 정체**(위 참조) · 지원/비지원 URL 목록 원문 · 파일명 매칭 규칙(확장자 포함 여부·대소문자)

# 판정 82 — 🔑 **데이터 태그 형식 = `$$열이름$$`** (7-4 · 2026-09-18)

> 📎 `7-4_데이터태그_「$$열이름$$」_형식.jpg`

## 실측 태그

에디터 텍스트에 **`$$이름$$ 회장님께`** 처럼 삽입된다. 확인된 태그:
`$$이름$$` · `$$ex. 휴대폰 번호$$` · `$$프로필 이미지$$` · **`$$CdBd URL$$`**

> 🔑 **열 이름을 그대로 `$$…$$`로 감싼다.** 기본 열 이름이 `ex. 이름`이면 태그도 **`$$ex. 이름$$`** 이다(접두사 `ex. `까지 포함).
> 🔑 **개별 URL 열도 `$$CdBd URL$$`로 삽입 가능** — 페이지 안에 자기 개별 URL을 넣을 수 있다.
> ✅ **미리보기에서 실제 값으로 치환됨** — 뷰어에서 **「박현수 회장님께」**·**「김재인 회장님께」** 확인.
> 🔑 **데이터가 없으면 태그 자리가 빈칸이 된다**(「회장님께」만 남음). 오류 표시가 아니다.

## ⏳ 미확인
- **「데이터」 버튼이 어디에 뜨는지**(지시서 ①) · **그룹 드롭다운 전체**(지시서 ②) — 조작 장면이 짧아 확정 못 함
- **링크 URL 입력란에도 삽입되는지**(지시서 ④)
- 태그를 **수동 타이핑**해도 되는지 · 존재하지 않는 열을 쓰면 어떻게 되는지

# 💰 판정 83 — 개별 URL = **1개당 1개월 5C · 1개월 단위 올림** · 🔴 **한글 데이터로는 못 만든다** (7-5 · 2026-09-18)

> 📎 `7-5_데이터지정하기_열선택+미리보기.jpg` · `7-5_사용할수없는데이터_슬러그규칙4줄.jpg` · `7-5_크레딧확인_1개당5C·1개월단위올림.jpg` · `7-5_개별URL생성후_CdBd URL열+QR배지.jpg`

## 1단계 — 「개별 URL 생성하기」 : 끝부분 정의

> 「개별 URL의 끝 부분을 어떻게 정의할까요?」

| 선택지 | 미리보기 |
|---|---|
| ⦿ **3글자 랜덤 생성** (기본) | `https://cdbd.in/{계정}/{슬러그}/` + 🔀 `???` |
| ○ **내 데이터 적용** | `https://cdbd.in/{계정}/{슬러그}/` + `data` |

## 2단계 — 「데이터 지정하기」 (내 데이터 적용 선택 시)

> 「개별 URL의 끝 부분으로 사용될 데이터를 지정해 주세요.」 + **열 드롭다운**
> ⓘ 「특수 문자는 포함할 수 없습니다.」 · ⓘ 「**공백은 자동으로 하이픈(-)으로 변경**됩니다.」
> **[데이터 편집하러 가기]** · **미리보기** `https://cdbd.in/{계정}/{슬러그} / 김재인`

## 🚨 그런데 — **한글은 거부된다**

「김재인」을 지정하고 진행하면 **「사용할 수 없는 데이터가 있습니다」** 모달:

> 「지정한 그룹 내에 URL 주소로 사용할 수 없는 데이터가 있습니다. 데이터를 수정한 후 다시 시도해 주세요.」
>
> | 슬러그 규칙 (원문 4줄) |
> |---|
> | **3~30자** 이내여야 합니다. |
> | **공백**을 포함할 수 없습니다. |
> | 🔴 **영문, 숫자, 언더바(_), 점(.)만** 사용할 수 있습니다. |
> | **점(.)으로 시작하거나 끝날 수 없습니다.** |
>
> [취소하기] / **[데이터 관리 바로가기]**

> 🔴 **「내 데이터 적용」은 한국 고객 이름으로는 사실상 못 쓴다.** 2단계 미리보기가 **한글을 그대로 보여줘서 될 것처럼 보이는데**, 다음 단계에서 막힌다.
> 🔑 **실무 결론** — 한글 이름 데이터면 **「3글자 랜덤 생성」**을 쓰거나, 영문 슬러그 열을 **별도로 만들어야** 한다.
> ✅ 실측도 랜덤으로 진행됐다 → 생성된 URL = `…/datatest/7M9`, `…/datatest/TM4`

## 💰 3단계 — 크레딧 확인 (**비용 게이트 핵심**)

> **「{N}개의 개별 URL 생성 시 / 총 {M} 크레딧이 차감됩니다.」**
>
> | 항목 | 실측 |
> |---|---|
> | 내 크레딧 | `870,864C` |
> | 개별 URL 수 | **2개** |
> | 이용 기간 | **30일** |
> | **차감 예정 크레딧** | **10C** |
>
> **각주 3줄 (원문)**
> - 「이용 기간: **기본 URL 만료일까지 남은 기간**」
> - 🔑 「**개별 URL 1개당 1개월 이용시 5C**」
> - 🔑 「**개별 URL 크레딧은 1개월 단위로 차감** (ex. 이용 기간 40일이면 **10C 차감**)」
>
> [취소하기] / **[개별 URL 생성하기]**

### 🎯 요금 공식

> **총 크레딧 = 개별 URL 개수 × ⌈이용 기간 ÷ 1개월⌉ × 5C**

> 🔴 **「이용 기간」은 고르는 게 아니다.** 지시서 7-5 ②는 *"이용 기간 **선택**"* 이라 적었지만, 실제로는 **기본 URL 만료일까지 남은 기간으로 자동 결정**된다. 사용자가 조절할 수 없다.
