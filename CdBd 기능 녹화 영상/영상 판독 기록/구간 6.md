# 판정 73 — 뷰어 사이드바엔 **「⋯ 더보기」가 없다** · 🔔=구독 / **♡=저장(좋아요 아님)** (6-1 · 2026-09-18)

> 📎 `6-1_PC사이드바_비로그인_🔔♡공유하기·QR.jpg` · `6-1_「페이지 구독하기」 모달_비로그인_이메일.jpg` · `6-1_「페이지 저장하기」 모달_메모입력란.jpg` · `6-1_구독후_🔔주황색_채워짐.jpg` · `6-1_저장후_♡빨강_채워짐.jpg`
> 대상 `cdbd.in/mustard73/test` (원페이지 · 발행됨) · **로그아웃 상태로 접속하는 과정까지 촬영**(0~12초)

## 🎯 PC 사이드바 구성 (위→아래)

| 위치 | 요소 |
|---|---|
| 상단 좌 | **CdBd 로고**(검정 원형) |
| 상단 우 | **🔍 검색** · **「‹」 접기** ← 🔑 **검색 아이콘이 여기 있다**(멀티에서만 노출 여부는 ⏳) |
| 중단 | **페이지 제목** → **썸네일 카드**(OG 미설정 시 CdBd 기본 이미지) |
| 버튼 행 | **🔔**(원형) · **♡**(원형) · 검정 **[⬆ 공유하기]** |
| 하단 | **QR 코드** + **[⬇ PNG]** · **[⬇ SVG]** |

> 🔴 **「⋯ 더보기」 메뉴는 존재하지 않는다.** 사전 §5의 *"⋯ 더보기 = 구독하기·저장하기·공유하기·검색하기"* 는 **틀렸다** — 그 기능들이 **아이콘으로 직접 노출**돼 있고 묶는 메뉴가 없다.
> ✅ 사전 §5 「PC 사이드바」 행의 **구성 요소 자체는 정확**했다(제목·썸네일·구독·공유·QR·접기).

## 🔴 **♡는 「좋아요」가 아니라 「저장하기」다**

| 버튼 | 실제 기능 | 로그인 |
|---|---|---|
| **🔔** | **페이지 구독하기** | ❌ 불필요 — **이메일만 입력** |
| **♡** | 🔴 **페이지 저장하기**(북마크 + 메모) | ✅ **필수** — 비로그인 클릭 시 **로그인 모달** |
| **[⬆ 공유하기]** | **macOS 네이티브 공유 시트** (AirDrop·메일·메시지·메모…) — 제품 자체 공유 모달이 아님 |

> ✅ **교차 증거** — 6-4의 URL 정보 편집 모달에서 「페이지 상단 메뉴」 토글 설명이 **「페이지 구독, 저장, 공유 기능이 표시됩니다.」** 다. **제품이 스스로 「저장」이라 부른다.**
> 📌 사전 §5의 「♡ **좋아요**」는 정정 대상.

### 실행 후 아이콘이 상태를 표시한다
- **구독 완료 → 🔔이 주황색으로 채워짐** + 녹색 토스트
- **저장 완료 → ♡가 빨간 하트로 채워짐** + 녹색 토스트

## 모달 원문

**「페이지 구독하기」** (✕ 있음)
> 썸네일 → **「{페이지명}의 소식을 빠르게 받아 보세요!」** → 입력란 placeholder **「이메일 주소를 입력해 주세요」** → 각주 **「개인정보 수집 및 이용과 광고성 정보 수신에 동의한 것으로 처리됩니다.」** → [취소하기] / **[구독하기]**
> 🔑 **[구독하기]는 이메일 입력 전 비활성**(연보라).

**「페이지 저장하기」** (✕ 있음)
> **페이지 제목** → 썸네일 → 입력란 placeholder **「페이지에 대한 메모를 남길 수 있어요.」** → [취소하기] / **[저장하기]**
> 🔑 **[저장하기]는 처음부터 활성** — **메모는 선택 입력**이다.
> ✅ 저장 결과가 **내 페이지 → 「저장한 페이지」 탭**에 메모와 함께 나타나는 것까지 확인(1:18~1:20).

# 판정 74 — 멀티 뷰어 컨트롤러 = **진행바 + 「N / M」 + 아이콘 4종** · 전체 페이지 보기는 **3열** (6-2 · 2026-09-18)

> 📎 `6-2_첫페이지_1의7_「‹」_미렌더링.jpg` · `6-2_마지막_7의7_「›」_미렌더링·이전페이지30%노출.jpg` · `6-2_전체페이지보기_3열그리드·툴팁.jpg` · `6-2_컨트롤러바_진행바·「1-2 7」·아이콘4종.jpg`
> 대상 `cdbd.in/2account/test1` (멀티 **7페이지** · 발행됨)

## ✅ 이전/다음 화살표 — 판정 67 **재확증**

| 위치 | 「‹」 | 「›」 |
|---|---|---|
| **1 / 7** | 🔑 **렌더링 안 됨** | 있음 |
| 중간 | 있음 | 있음 |
| **7 / 7** | 있음 | 🔑 **렌더링 안 됨** |

> ✅ **다른 문서(7페이지)에서 독립 재현** — 판정 67(6페이지 문서)과 동일. **비활성이 아니라 사라진다**는 게 확정됐다.
> 🆕 **`[DS] 3-12`의 「이전/다음 페이지 미리보기 W:380 opacity 30% 좌측/우측 부분 노출」이 실측으로 확인됐다** — 인접 페이지가 반투명으로 옆에 걸쳐 보인다.

## 🎯 하단 컨트롤러 바 (좌→우)

**보라색 진행 바**(현재 페이지 비율로 채워짐 · 1/7에서 0%, 7/7에서 100%) → **페이지 카운터** → **아이콘 4종**

| 아이콘 | 툴팁(판정 67) | 실측 동작 |
|---|---|---|
| **⊞** | 「전체 페이지 보기」 | 어두운 오버레이 + 썸네일 그리드 |
| **▯** | (⏳ 미확인) | 한 페이지씩 — 세그먼트 좌 |
| **▯▯** | 「두 페이지씩 보기」 | 세그먼트 우 |
| **⛶** | 「화면 채우기」 | — |

> 🔑 **▯ / ▯▯는 개별 버튼이 아니라 하나의 세그먼트 컨트롤로 묶여 있다**(선택된 쪽만 진하게). ⊞와 ⛶는 독립 버튼.

## 🔴 카운터 표기 — 지시서의 「1/30」 가정과 다르다

| 모드 | 표기 | 예 |
|---|---|---|
| 한 페이지씩 | **`N / M`** (공백 있음) | `1 / 7` · `7 / 7` |
| **두 페이지씩** | **`N-N / M`** | `1-2 / 7` · `5-6 / 7` |
| 두 페이지씩 + **마지막이 홀수** | 🔑 **`7 / 7`** (한 장만 남으면 단일 표기로 돌아감) | — |

> ✅ 판정 70의 「1-2 / 4」 형식이 **다른 문서에서 재확인**됐다.

## 🔴 전체 페이지 보기 = **3열** (판정 67은 「5열」)

> 이번 실측(7페이지 · 사이드바 펼침 상태)은 **3열 그리드**다. 판정 67은 **5열**로 기록했다.
> ⚠️ **어느 쪽이 틀렸다고 단정하지 않는다** — 판정 67은 **6페이지 문서**였고 창 폭·사이드바 상태가 달랐을 수 있다. **열 수는 반응형일 가능성이 높다.**
> 🔑 **자동화·안내에 「N열」을 고정값으로 쓰지 말 것.** ⏳ 열 수 결정 규칙 미확정.

**구성** — 어두운 오버레이 · 썸네일 **번호 라벨**(1~7) · **현재 페이지 파란 테두리** · 하단 컨트롤러 바와 카운터 **유지**.

## URL 규칙 — 🔴 판정 67 정정

> 판정 67: *"2페이지부터 **`&page=N`** 이 붙는다"*
> **실측: `cdbd.in/2account/test1?page=5`** — 🔑 **앞에 다른 파라미터가 없으면 `?page=N`이다.** 1페이지일 때 파라미터가 없는 것은 동일.

## ⏳ 미확인
- **▯(한 페이지씩) 툴팁 원문** (여전히)
- **화면 채우기**가 정확히 무엇을 바꾸는지(배율? 여백?) — 전환은 확인, 차이 미측정
- 전체 페이지 보기에서 **썸네일 클릭 → 이동**(판정 67에서도 미확인)
- **스와이프**(트랙패드/터치) 동작 — 이번엔 화살표 클릭만
- 진행 바 **드래그 가능 여부**

# 판정 75 — 페이지 검색 = **사이드바 우측 별도 컬럼** · 결과 없음은 **「0건」뿐** (6-3 · 2026-09-18)

> 📎 `6-3_검색패널_「2건」·N페이지·볼드하이라이트.jpg` · `6-3_검색결과없음_「0건」만·빈상태문구_없음.jpg` · `6-3_결과클릭_URL「?page=5」·카운터「5-6 7」.jpg`

## 진입·레이아웃

**사이드바 상단 우측 🔍** 클릭 → 🔑 **사이드바 오른쪽에 검색 패널이 별도 컬럼으로 붙고 뷰어 영역을 밀어낸다.** (사이드바를 덮지 않음 · 오버레이 아님)

| 요소 | 내용 |
|---|---|
| 상단 | **✕** (우측) |
| 입력란 | 🔍 + placeholder **「검색어를 입력하세요」** |
| 빈 상태(입력 전) | **「찾고 싶은 내용을 / 검색해 보세요」** (2줄) |
| 결과 수 | **「N건」** (예 「2건」) + 우측 **「‹ ›」 페이지네이션** |
| 결과 항목 | **「N 페이지」**(굵게) + 본문 발췌 + 우측 **「›」** · 호버 시 회색 배경 |

## 🔑 검색어가 **볼드로 하이라이트**된다
발췌문 안의 검색어가 굵게 표시되고, **한 항목에 여러 번 나오면 전부 하이라이트**된다(「사전」 2곳 확인).

## 🔴 결과가 없을 때 — **빈 상태 문구가 없다**

「레」·「레에」·「레구매하」·「구매하기」 4회 모두 **「0건」만 표시되고 목록 영역이 그냥 빈 채로 남는다.**
> ✅ **「없다」를 4개 검색어 × 각 2초 이상으로 확인.** 안내 문구·일러스트·재시도 유도 **전무**.
> 📌 지시서 6-3 ③ *"결과 없을 때 빈 상태 문구"* 는 **기능 부재**로 답이 나왔다.

## ✅ 결과 클릭 → 해당 페이지로 이동
「5 페이지」 결과 클릭 → **URL `?page=5`** · 카운터 **「5-6 / 7」**(두 페이지씩 보기 상태였음) · **검색 패널은 열린 채 유지**.

## ⏳ 미확인
- 검색 범위 — **카드 본문만인지 제목·버튼 라벨까지인지**
- **대소문자·띄어쓰기·부분어** 처리 (한글 부분어 「사전」은 매칭됨)
- 결과가 많을 때 **「‹ ›」 페이지네이션**의 실제 동작 (2건에서도 표시됨 → 항상 노출 추정)
- **원페이지 뷰어에도 🔍가 있는지** (6-1 사이드바엔 아이콘이 있었으나 클릭 안 함)

## 🚨 보안 — 새 유형
🔴 **검색 입력란에 브라우저 자동완성 드롭다운이 떴다**(`100`·`20`·`0`·`10`·`26FW`·`30`) — **제품 UI가 아니다.** 판독 시 제품 요소로 오인하기 쉽다. 촬영 시 자동완성을 꺼두는 게 좋다.
