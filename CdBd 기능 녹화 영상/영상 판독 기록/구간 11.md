# 판정 139 — 삭제된 페이지로 걸린 링크: **링크 칸은 빈칸 · 미리보기 클릭은 무반응** (11-3)

> 📎 `11-3_페이지삭제후_링크칸빈칸·목록1-3.jpg`

- **설정 형식** — 「링크 연결」 첫 칸 「페이지 이동하기」 + 둘째 칸 = **숫자 드롭다운**(1·2·3·4) · 고르면 칸에 `4` + 회색 접미어 「페이지」 (t8~16) — 「4페이지」라는 한 덩어리 문자열이 아니다
- 삭제 전 미리보기 → `1 / 4`에서 `4 / 4`로 이동 · URL에 `&page=4` (t17~20)
- 삭제 확인 = 「페이지 삭제하기」 / 「삭제한 페이지는 복구할 수 없습니다. 정말 삭제할까요?」 / [취소하기] [삭제하기] (t31~33) — 기존 판정 69와 동일
- 🔑 **삭제 후 링크 칸 = 첫 칸 「페이지 이동하기」 유지 · 둘째 칸 빈칸**(회색 「페이지」만) · 펼치면 「1·2·3」뿐이고 **선택 강조 없음** (t39~55) · 캔버스의 버튼 링크 배지는 남아 있다(t42)
- 🔑 **삭제 후 미리보기에서 버튼 → 이동 없음 · 에러 없음** — `1 / 3` 유지, URL 변화 없음 (t59~62)
  - ◐ 클릭 링이 보이지 않아 **실제 클릭 여부는 커서 위치로만 판단** — 「무반응」은 ◐로 둔다
- 🔗 2026-10-02 자동화 관찰(editor 6468)과 합치면: **데이터엔 지워진 pageId가 남고, UI는 빈칸으로 보이며, 방문자 화면에선 아무 일도 일어나지 않는다** → 목차·메뉴 링크가 **조용히 죽는다**
- ⚠️ 11-5 시작(t2)에선 같은 버튼이 「1 페이지」로 보인다 — 그 사이 누가 바꿨는지 영상에 없음

# 판정 142 — 이미지 디자인 보드 전체 · 🔑 **썸네일 ⋯를 누르면 그 페이지가 현재 페이지가 된다** (11-6)

> 📎 `11-6_이미지보드_모양8종.jpg` · `11-6_썸네일더보기클릭_현재페이지전환.jpg`

**(a) 이미지 디자인 보드 — 위→아래** (t4·12·13·21)
| 섹션 | 내용 |
|---|---|
| 비율 | **원본**(기본) / 1:1 / 가로↔ / ↕세로 |
| 크기 | 슬라이더 + 숫자 칸 · 기본 100 · 🔑 **슬라이더 범위 10~100**(끝까지 끌어 t26~27 = 10, t31 = 100) |
| 정렬 | 왼쪽 / **가운데**(기본) / 오른쪽 |
| 모양 (펼침) | 🆕 **8종 = 각진(기본) · 둥근 · 원형 · 아치 · 구름 · 꽃 · 반짝이 · 마름모** |
| 확대 보기 (펼침) | **허용**(기본) / 허용안함 |
| (접힘) | 링크 연결 · 카드 디자인 · 레이어 추가 |

**(b) ⋯ 메뉴의 대상**
- `1 / 3`에서 3번 썸네일에 **호버만** 하면 파란 테두리, 카운터는 `1/3` 그대로
- 🔑 **⋯를 누르는 순간 `3 / 3`으로 바뀌고 캔버스도 3페이지로 전환**(t39 · 「복제하기」 누르기 **전**)
- 복제하기 → `4 / 4` · 복사본은 **4번(3번 바로 뒤)** · 내용 = 3페이지와 동일 · 현재 페이지 = 복사본(t40~47)
- 🔑 11-4에서도 같은 현상(⋯ 클릭 시 `2/5`로 전환 · t14)
- 🔁 **2026-10-02 자동화 관찰 보정** — 「현재 페이지는 그대로, 대상만 호버한 썸네일」이 아니라 **⋯를 여는 순간 그 페이지가 현재 페이지가 된다**. 대상이 호버한 썸네일인 건 맞다

# 판정 144 — 페이지 설정 **✕ = 변경 폐기** · 내보내기엔 **배율 옵션이 없다** · PDF는 **.pdf 한 개** (11-8)

> 📎 `11-8_X로닫으면_변경폐기(640유지).jpg` · `11-8_내보내기팝오버_배율옵션없음.jpg` · `11-8_JPG_760x1280.jpg`
