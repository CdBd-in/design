## 🎯 4컬럼 — 원페이지 3보드 **앞에 「페이지 목록 패널」이 추가**된 구조

**상단바** — 로고 · `←` `→` · 페이지 제목 「새로운 페이지 ✏️」 · ☁「자동저장 중」 · **⚙** · **💡** · **🎨** · │ · **👁** · 보라 **[URL 생성하기]**

## 페이지 목록 패널 — 접기/펼치기

| 상태 | 헤더 | 그리드 | 토글 | 미리보기 |
|---|---|---|---|---|
| **접힘** | **「N / M 페이지」** (현재/전체) | **세로 1열** | 「**›**」 | 안 가림 (독립 컬럼) |
| **펼침** | **「M 페이지」** (전체만) | 🔑 **5열 그리드** | 「**‹**」 | **오버레이로 덮음** |

> 🔑 **헤더 표기가 상태에 따라 다르다** — 접힘은 「3 / 6 페이지」, 펼침은 「6 페이지」.
> [+ 페이지 추가]는 **두 상태 모두 패널 바깥 좌상단에 유지**.

### 페이지 썸네일 ⋯ 메뉴 = **4항목**
「복제하기」 · 「삭제하기」 ─ **「페이지 배경 설정」** · **「페이지 정렬 설정」**
> 🆕 뒤 두 항목은 **페이지 단위 설정**으로, 카드 ⋯ 메뉴(7항목)와 완전히 다르다.

## 🚨 이전/다음 이동 버튼 — **에디터엔 없다. 뷰어에만 있다**

에디터(`/editor/{id}`) 전 구간(0:07~0:38)에 좌우 이동 화살표가 **없다.**
페이지 전환은 **페이지 목록 썸네일 클릭**으로만 한다.
> ⚠️ 상단바 좌측 `←` `→`는 **전 구간 ← 진함 / → 흐림 고정**. 페이지 1/2에서도 ←가 진했으므로 **페이지 이동 버튼이 아니다**(실행취소/다시실행 추정 · ⏳ 라벨 미확인).

**뷰어(`/editor/{id}/viewer`)** — 미리보기 좌·우에 검정 원형 **「‹」「›」**

| 위치 | 「‹」 이전 | 「›」 다음 |
|---|---|---|
| **첫 페이지** | 🔑 **요소 자체가 렌더링 안 됨** | 있음 |
| 중간 | 있음 | 있음 |
| **마지막** | 있음 | 🔑 **요소 자체가 렌더링 안 됨** |

> 🔑 **「비활성(회색)」이 아니라 사라진다.** **순환(첫↔끝 wrap) 없음.**
> ✅ 두 판정 프레임 모두 **모달 오버레이가 없는 상태**에서 확인 (오버레이 오인 방지 규칙 준수).

## 뷰어 하단 바 — 아이콘 4종 (툴팁 원문)
**⊞ 「전체 페이지 보기」**(어두운 오버레이 + 5열 그리드) · ▯ 1페이지 보기(툴팁 ⏳) · **▯▯ 「두 페이지씩 보기」**(카운터가 「3-4 / 6」 형식으로 바뀌고 **2페이지씩 이동**) · **⛶ 「화면 채우기」**
좌측 사이드바 — 로고 · 🔍 · 「‹」 · 페이지명 · 🔔 / ♡ / **[⬆ 공유하기]** · 하단 **QR + [⬇ PNG][⬇ SVG]**

> 🔑 **뷰어 URL은 `page=1`일 때 파라미터가 아예 없다** — 2페이지부터 `&page=N`이 붙는다.

## 🆕 「+ 새 페이지」 = **3단계 모달** (판정 49의 `/templates`와 다른 경로)

| 단계 | 제목 | 선택지 |
|---|---|---|
| 1 | **「페이지 주제를 선택해 주세요.」** | **빈 페이지로 시작하기** / 초대 · 예약 / 홍보 · 카탈로그 / 프로필 · 명함 *(뒤 3개엔 [템플릿 확인하기])* |
| 2 | **「만들고 싶은 모바일 페이지 유형을 선택해 주세요.」** | **원페이지**(*"…상하 스크롤 방식으로 전달합니다."*) / **멀티페이지**(*"…한장씩 넘겨보는 방식으로 전달합니다."*) |
| 3 | **「페이지 사이즈를 선택해 주세요.」** | 🔑 **「추천」 배지 + `380×580px`** (*"대부분의 모바일 브라우저에 최적화된 사이즈예요"*) + [시작하기] / **「직접 입력」 — 가로 `380`(고정) × 세로 입력** |

> 🔑 **가로는 380px 고정**이고 세로만 입력할 수 있다. 팀 규격(380px)의 근거가 제품에 있었다.
> 🔑 **신규 멀티페이지는 기본 2페이지**로 생성된다.
> 🔑 **[+ 페이지 추가]는 맨 뒤에 추가하고 새 페이지를 즉시 선택**한다(2→3→4→5→6 연속 관측).

# 판정 68 — 스크롤 애니메이션 **3종** · **저장하기 필수** · 적용 범위 3분리 (5-4 · 2026-09-16)

> 📎 `5-4_스크롤애니메이션_팝오버_위로·확대·없음.jpg` · `5-4_헤더비교_미발행vs발행_🌐추가·게시하기.jpg`
> 🔬 **판독 품질 주목** — 8fps 연속 프레임에서 **y좌표·크기·투명도 변화를 추적**해 애니메이션을 증명했다. 정지 프레임 비교로 단정하지 않았다.

## 진입 — 💡 = **「스크롤 애니메이션」** (팝오버 · 모달 아님)

- 💡 호버 툴팁 **「스크롤 애니메이션」** / 🎨 호버 툴팁 **「페이지 테마」**
- 💡 클릭 → **아이콘 바로 아래 앵커된 팝오버**. **배경 딤 없음** (같은 영상의 「내 카드로 저장하기」 모달은 딤됨 → 대조로 확인)
- 하단 버튼 2개 — **[닫기]** / **[저장하기]**(보라)

## 선택지 **3종** (설명문 없음 · 라벨만)

| 순서 | 원문 | 썸네일 |
|---|---|---|
| 1 | **「위로」** | 사각형이 **아래→위 이동 + 페이드인** |
| 2 | **「확대」** | 사각형이 **작게→크게 + 페이드인** |
| 3 | **「없음」** | ⊘ 아이콘 (썸네일 없음) |

> 🔑 **썸네일이 정지 이미지가 아니라 실제로 도는 루프 프리뷰**다.
> ⚠️ **선택 = 파란 테두리 + 우상단 파란 체크 / 호버 = 파란 테두리만.** 체크 유무로만 구분된다.

## 🔑 [저장하기]를 눌러야 커밋된다

| 근거 | 내용 |
|---|---|
| ① | **선택 클릭만으로는 「자동저장 중」 인디케이터가 뜨지 않는다** (3라운드 01:05.0 클릭 직후 프레임 확인) |
| ② | **[저장하기] = 저장 + 팝오버 닫기** (3회 모두 클릭 즉시 소멸) |
| ③ | 2라운드에서 뜬 「자동저장 중」은 **선택 클릭 이전부터** 떠 있었다 → 주기적 자동저장이지 선택과 무관 |

⏳ **[닫기]·✕로 닫으면 선택이 폐기되는지는 미실험.**

## 🎯 적용 범위 — **3곳이 다 다르다**

| 대상 | 애니메이션 | 근거 |
|---|---|---|
| **게시된 라이브** (`cdbd.in/{주소}/{슬러그}`) | ✅ 재생 | 「위로」 = y 294→243px 이동 + 페이드 / 「확대」 = **y 고정(126/256/385→123/253/382)** + 크기 변화 → **두 효과가 명확히 구분됨** |
| **에디터 미리보기** (`/editor/{id}/viewer`) | ✅ 재생 | 「확대」 확인 (y 고정 + 크기 변화) |
| **에디터 편집 캔버스** (폰 목업) | ❌ **재생 안 됨** | 스크롤해도 요소가 **100% 불투명·최종 위치·최종 크기** (8fps 10프레임 전부) |

### 🔑 결정적 — **게시하지 않아도 미리보기엔 반영된다**
3라운드에서 「위로」 선택 → **[저장하기]만** 하고 **게시하지 않음**(게시 팝오버 없음 확인).
→ 미리보기 탭 **전환만 했을 땐 갱신 안 됨**(이전 상태 유지 · `refresh` 토큰 동일)
→ **브라우저 새로고침** 후 **「위로」가 재생됨**(y 185→123px)

> 🔑 **저장만으로 `/viewer`에 반영되나, 반영을 보려면 새로고침/재진입이 필요하다.**
> ⏳ **저장만 한 값이 라이브에도 반영되는지는 미확정** — 1·2라운드는 전부 저장→게시 순서였고, 3라운드 후 라이브 탭을 다시 열지 않았다.

## 🔑 재생 시점 — **페이지 로드 시 1회**
라이브에서 로드 애니메이션이 끝난 뒤 실제로 스크롤한 구간(00:25.6~26.5)에서 들어오는 행들은 **전부 불투명·최종 위치**. **스크롤 중 재재생 없음.**

## 🆕 「스크롤 발생」 마커
편집 캔버스 폰 목업 위에 **연두색 점선 + 연두 배지 「스크롤 발생」**이 떠 있다. 한 화면 분량을 넘어가는 지점을 표시하는 가이드.

## 🎯 교차 확인 — **헤더는 게시 여부에 따라 달라진다** (구간 1 미해결분 해소)

| 상태 | 헤더 우측 |
|---|---|
| **미발행** (5-1) | ⚙ 💡 🎨 │ 👁 │ **[URL 생성하기]** |
| **발행됨** (5-4) | ⚙ 💡 🎨 │ 🆕 **🌐** 👁 │ **[게시하기 ▾]** |

> ✅ **구간 1-1 ④번**(*"URL 버튼 라벨이 `URL 생성하기`인지 `게시하기`인지"*)의 완전한 답.
> 🆕 **발행 후 🌐(지구) 아이콘이 추가**된다는 건 어느 정본에도 없던 내용. **[게시하기]에는 ▾ 드롭다운**도 붙는다.

### 🔑 「중간화질 / 고화질」은 **해상도 차이가 아니다 — 압축 차이다**

**픽셀 동일성 검증** — 같은 페이지의 JPG·WebP를 PNG(무손실) 기준으로 채널 비교:

| 비교 | 평균 채널 차이 | 최대 |
|---|---:|---:|
| JPG vs PNG | **0.70** | 15 |
| WebP vs PNG | **0.83** | 13 |

> 🔑 **동일한 렌더 결과**이고 차이는 순수 손실압축 아티팩트뿐이다.
> 🔴 **따라서 *"고화질이 필요하니 PNG로 뽑자"* 는 해상도상 아무 이득이 없다.** 픽셀은 JPG와 똑같고 **용량만 5.5배**다.
> 🔑 **PNG는 RGBA지만 전 픽셀 알파 255(완전 불투명)** — 투명 배경이 아니다. **알파 채널이 용량만 키우고 실익이 없다.**
> 💡 **용량 순위 = WebP < JPG < PNG** (2페이지: 327KB < 374KB < 2,060KB). 제품 설명문 「웹용/고화질, 저용량」·「고화질, 대용량」이 실측과 일치.

## 🚨 결론 2 — **PDF는 「인쇄용」이라 적혀 있지만 인쇄에 못 쓴다**

| 항목 | 실측 |
|---|---|
| 파일 구성 | 🔑 **`JOINUS.pdf` 1개 문서에 2페이지** — 래스터처럼 페이지별로 쪼개지지 **않는다**(판정 71의 ⏳ 종결) |
| 파일명 | **「제목.pdf」** — 페이지 번호가 **안 붙는다**(래스터는 「제목-N.ext」) |
| 생성기 | **jsPDF 3.0.4** → **브라우저(클라이언트)에서 생성** |
| 페이지 크기 | `MediaBox 0 0 570 870` **pt** = 7.92 × 12.08 in = **약 201 × 307 mm**(A4 근사) |
| 내부 구조 | 페이지당 **760×1160 래스터 이미지 1장**을 통째로 배치 (`/Contents` 길이 **50바이트** = 이미지 배치 명령뿐) |
| 🔴 **텍스트 레이어** | **없음.** `Tj`/`TJ` 연산자 **0개** — 텍스트 선택·검색·복사 **불가**. `/Type /Font` 14개는 jsPDF 기본 리소스일 뿐 실제로 쓰이지 않음 |
| 🔴 **압축** | **없음.** `/Filter` 부재 · `/Length 2,644,800` = 760×1160×3 **정확히 일치** → **무압축 RGB 비트맵** |
| 용량 | **5,293,280 B (5.05 MB)** / 2페이지 — 같은 내용 **WebP 2장 합계 334KB의 약 16배** |
| 🔴 **실효 해상도** | 760 px ÷ 7.92 in = **약 96 DPI** |

> 🚨 **실무 결론 — 「인쇄용 / 문서 공유용」 라벨을 믿고 인쇄 납품하면 안 된다.**
> 상업 인쇄 기준은 **300 DPI**인데 실효 **96 DPI**다. 용지 크기만 A4에 가깝고 **해상도는 웹 수준**이다.
> 🔑 **300DPI 인쇄물이 필요하면 CdBd 내보내기로는 불가** — 별도 원고 제작이 필요하다.
> 💡 **PDF의 실제 용도는 「문서 공유용」쪽이다.** 다만 **텍스트가 이미지라 검색·복사가 안 되고 5MB**라 메일 첨부에도 불리하다.
