# 판정 177 — 예약 순서: **본인 인증이 먼저, 옵션 선택은 그 뒤** (12-1)

> 📎 `12-1_본인인증창_객관식추가문항.jpg` · `12-1_인증뒤_인원→날짜→시간.jpg`

- 뷰어의 예약 카드 = 버튼 하나 **[예약하기]** (t0) — 카드 위에 날짜·시간 목록이 미리 보이지 않는다
- [예약하기] → 🔑 **바로 「본인 인증하기」 창**(t2) — 이름 *필수 · 추가 문항 *필수 · 휴대폰번호 *필수 + [인증번호 받기] · 인증번호 *필수 · 링크 「인증번호 문자가 오지 않을 때」 · ☐ 「개인정보 수집 이용 고지 (필수)」 + 「자세히」 · [다음](비활성)
  - 「자세히」 → 「개인정보 수집 이용 고지(안내)」 전체 화면(t19) — 편집기의 고지 문구가 그대로 나온다
  - 동의까지 채우면 [다음]이 검정으로 켜진다(t21)
- [다음] → 「예약하기」 화면 ① **「인원을 입력해 주세요」**(숫자 칸 · 단위 「명」) + [다음] + 아래 「예약 내역」 제목(t22~23)
- ② **「날짜를 선택해 주세요」** — 달력 `10월 2026` · 예약 가능한 날만 진하게 · 16일 선택(t24~25)
- ③ **「시간을 선택해 주세요」** — 시간 칩(`19:45`) 선택 → [예약하기] → 「예약 처리중...」(t26~28)
- ④ **「예약 완료」 화면**(t29~31) — 파란 라벨 「예약 완료」 · 제목 · 장소 · **예약자 정보**(이름·연락처) · **예약 내용**(일시 `2026.10.16(금) 19:45` · 인원 `2명`) · **호스트 정보**(이름·연락처) · 아래 [예약 취소] + 공유 아이콘
- 🔑 지시서는 「옵션을 고른 뒤 인증」으로 가정했지만 **실제는 반대 순서**다 — 인원·날짜·시간은 인증을 통과해야 보인다
- ⏳ **옵션이 여러 개일 때 표시** — 두 페이지 모두 옵션 1개라 관측 못 함(날짜 1개 · 시간 칩 1개)
