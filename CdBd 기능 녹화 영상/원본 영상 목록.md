## 📛 이름 규칙 (2026-09-27 제정)

| 종류 | 형식 | 예 |
|---|---|---|
| **최상위 폴더** | `CdBd 기능 녹화 원본` | (옛 `CdBd  전기능 녹화` — 공백 2칸 · 옛 g1 `CdBd 기능 녹화 영상`) |
| **구간 폴더** | `구간 N` (공백 1칸) | `구간 6` (옛 표기 `구간6` ❌) |
| **본편 클립** | `{코드}. {대본 제목}.mov` — 제목은 [[촬영 지시서 — 70클립 대본]]의 헤딩을 따른다 | `1-2. 카드 보드 — 추가·순서·토글.mov` |
| **합본 클립** | `{코드}·{코드}. {제목} + {제목}.mov` | `6-2·6-3. 멀티 뷰어 조작 + 페이지 검색.mov` |
| **보충** | `보충 {MMDD} {라벨}. {내용} ({판정 또는 대응 구간}).mov` — 라벨 = 클립 코드·`동선N`·`추가N` (없으면 생략) | `보충 0920 동선5. 통계 (구간 8).mov` |
| **보충 위치** | 특정 구간 1개에 속하면 **그 구간 폴더** · 여러 구간을 도는 세션이면 `보충영상/` | 사이드바 보충은 구간 6 판독이라 `구간 6/`으로 이동 |

**문자 규칙** — 구분은 ` — `(말줄임 대시) · 나열은 `·` · 결합은 ` + ` · `:` `/` `,` `&` 와 끝 공백 금지(드라이브·맥 경로에서 깨짐).
**✅ g1 적용 완료 (2026-09-29)** — 구간 2·3·4·5 24개 변경 → 아래 「g1 분」 대응표. 구간 1은 MBP와 동일 영상이라 미적용.

## 🔀 두 기기 합치는 법 (V-5)

1. g1에서 `영상-목록.sh`로 해시 목록 생성 → 이 문서에 **g1 절** 추가
2. g1 파일 이름을 위 규칙으로 변경(판독 기록 인용도 함께 · 되돌리기 기록 남김)
3. **해시가 이 목록에 이미 있는 파일 = 같은 영상 → 업로드 생략**(구간 1 8개가 그럴 것으로 추정)
4. 이름은 같은데 해시가 다르면 → 뒤에 ` (g1)`을 붙여 둘 다 보관
5. 나머지만 드라이브 `CdBd 기능 녹화 원본/` 같은 구간 폴더에 추가 업로드
