## 왜 찍나 — 고객 화면은 거의 「설정 화면」과 「PC」로만 확인돼 있다

지금까지 근거의 한계는 세 가지다.
1. **카드 기능은 에디터 설정 화면**으로 확인했다 — 링크 연결 8종이 **있다**는 건 알지만, 고객이 누르면 **폰에서 무엇이 열리는지**는 안 찍었다.
2. **뷰어는 PC 브라우저**로 찍었다 — 공유하기는 「macOS 공유 시트」로만 관측됐다.
3. **모바일(구간 10)은 Chrome 에뮬레이션**이다 — 사전 §11 스스로 *「터치 제스처·모바일 브라우저·실기기는 미검증」*이라고 적고 있다.

## 1순위 — 고객이 가장 많이 누르는 것

### 13-1. 질문과 답변 — 막힘과 제출 (고객 폰 · 약 4분)
**왜** 지금은 에디터 미리보기의 폼 모양과, 호스트 통계에 답이 쌓인다는 것만 안다. **고객이 [제출]을 누른 뒤 무엇을 보는지** 기록이 없다.

1. 페이지를 폰에서 열고 Q 카드까지 스크롤 [정지] (질문 전체가 읽히게)
2. **아무것도 입력하지 않고 [제출]** → [정지] — 에러 문구 · 어느 질문이 표시되는지 · 스크롤 위치
3. 복수 선택 질문에서 2개 선택 [정지] → 단일 선택 질문에서 하나 고른 뒤 **다른 것을 다시 고르기** [정지]
4. 주관식 칸을 누름 → **폰 키보드가 입력란을 가리는지** [정지]
5. 상담 신청서의 전화번호 칸에 `abc` 입력 → [제출] [정지] (형식 검사가 있는지)
6. 제대로 채우고 [제출] → **제출 직후 화면** [정지] — 토스트 · 감사 문구 · 폼이 비워지는지 · [제출]이 비활성되는지
7. **바로 한 번 더 [제출]** → [정지]
8. **새로고침** 뒤 같은 폼 [정지] → 다시 제출 [정지] (같은 사람이 여러 번 낼 수 있는지)
9. PC 통계 「제출된 답변」 → 건수 배지 [정지] (7·8이 몇 건으로 쌓였는지)

**영상에 반드시 보여야 할 것**
- 필수 누락 에러 · 형식 검사 결과 · 제출 직후 화면 · 두 번째·세 번째 제출 결과 · 통계 건수

### 13-2. 질문과 답변 — 개인정보 동의 (고객 폰 · 약 1분)
**왜** 예약은 「개인정보 수집 이용 고지 (필수)」 체크가 있다(판정 36). 상담 신청서 프리셋은 이름·연락처를 받는데 **동의 체크가 있는지** 모른다 — 고객 안내 문구에 바로 쓰인다.

1. Q 카드 맨 아래 [제출] 주변을 확대해 [정지] (동의 체크·고지 문구 유무)

### 13-3. 링크 연결 실행 — 버튼 L1~L7 (고객 폰 · 약 6분 · OS별로)
**왜** 「전화 걸기 버튼 만들어줘」 같은 요청에 **고객이 실제로 겪는 결과**로 답하려면 필요하다.

각 버튼마다: **누르기 직전 [정지] → 누른 직후 [정지] → 폰 뒤로가기로 페이지 복귀 [정지]**

| 버튼 | 누른 뒤 볼 것 |
|---|---|
| L1 URL 열기 | 같은 탭인지 새 탭인지(주소창 · 탭 수) |
| L2 전화하기 | 다이얼 화면 · 번호가 채워졌는지 — **통화 누르지 않음** |
| L3 문자 보내기 | 문자 앱 · 받는 번호 · **기본 내용이 본문에 들어가는지** — 보내지 않음 |
| L4 이메일 보내기 | 어느 메일 앱이 뜨는지 · 받는 주소 — 보내지 않음 |
| L5 카카오톡 공유하기 | 카톡 앱 전환 · **공유 카드 모양**(제목·썸네일·버튼) → 「나와의 채팅」에 보낸 뒤 그 카드를 눌러 페이지가 열리는 화면 |
| L6 연락처 저장하기 | 연락처 추가 화면 · **채워진 항목** → 저장 후 연락처 앱 [정지] → **촬영 뒤 삭제** |
| L7 선택 카드로 이동하기 | 스크롤 이동 모양 · 도착 위치 |

**영상에 반드시 보여야 할 것**
- 7개 각각 누른 직후 화면 · L3 문자 본문 · L5 카톡 공유 카드 · L6 연락처 입력 항목

### 13-4. 위치 안내 버튼 (고객 폰 · 약 2분)
1. M1(구글맵) 지도 [정지] → 지도를 손가락으로 끌어 보기 [정지](페이지 스크롤과 지도 이동 중 무엇이 되는지) → 버튼 누르기 → 열린 앱·웹 [정지]
2. M2(네이버맵) 같은 순서 [정지]
3. 지도 앱이 설치되지 않은 폰이면 그 결과도 [정지]

## 2순위 — 상단 메뉴 · 구독 · 저장 · 공유

### 13-5. 페이지 상단 메뉴(모바일) 모양 (고객 폰 · 약 1분)
1. 페이지를 처음 열었을 때 화면 위쪽 [정지]
2. 아래로 스크롤 → 메뉴가 따라오는지 / 사라지는지 [정지]
3. 메뉴 항목을 하나씩 가리키며 [정지] (구독 · 저장 · 공유 아이콘 모양)

### 13-6. 🔔 구독하기 → 메일 → 해지 (고객 폰 · 약 4분)
> 이메일은 **팀 테스트 메일 주소**를 쓴다(실제 고객 메일 ❌).

1. 🔔 → 「페이지 구독하기」 모달 [정지] → 이메일 입력 → [구독하기] → 결과 [정지]
2. 폰 메일 앱 → **구독 확인 메일이 오는지** 2분 대기 [정지] (오면 전문 · 링크)
3. 메일에 해지·취소 링크가 있으면 눌러 **구독 취소 완료 화면** [정지] ← 사전 「확보 불가」 항목
4. 링크가 없으면 페이지로 돌아와 🔔 다시 누르기 → 「페이지 구독 해지하기」 → [해지하기] [정지]
5. PC 통계 「구독 현황」 → 목록에서 사라졌는지 [정지]
- 🚨 **PC 통계의 [구독 해지]는 누르지 않는다** — 「복구할 수 없습니다」(비가역)

### 13-7. ♡ 저장하기 — 비로그인 (고객 폰 · 약 2분)
1. **로그인 안 한 폰 브라우저**에서 ♡ → 로그인 모달 [정지]
2. 로그인 화면으로 가는 버튼이 있으면 눌러 화면 [정지] — **로그인은 하지 않는다**(공용 계정 세션을 폰에 남기지 않음)
3. 닫고 페이지로 돌아오는지 [정지]

### 13-8. 공유하기 · 받은 링크 미리보기 (고객 폰 · 약 3분 · OS별로)
